## 视觉基线与命令

- `corepack pnpm ui-samples:verify`：运行 29 页加载、接线、交互、控件几何、模块几何、排版间距和视觉完整性审计；
- `corepack pnpm visual:test`：运行 HTML 与已迁移 React 的严格截图对照；
- `corepack pnpm visual:react`：只运行已迁移 React 页面对照；
- `corepack pnpm visual:modes`：运行主页九模式根 token、计算色值、文案、焦点和截图对照；
- `corepack pnpm visual:components`：运行设计系统关键组件 HTML/React 双源裁切对照，执行 0.1% 差异门禁。

核心全页集合为 29 页 × 3 视口，共 87 张 HTML 权威基线。主页默认 standard 已包含在核心集合；其余八种玩法逐一点击后再按三视口截图，形成 24 张模式交互派生基线，全页视觉参照共 111 张。另有运行状态、语义状态组和模式身份卡三类关键组件 × 三视口，共 9 张裁切基线；当前目录共 120 张 PNG，统一位于 `tests/visual/baselines`。

全页使用 `threshold: 0.15`、`maxDiffPixelRatio: 0.003`；关键组件上限为 0.1%。失败时查看 `test-results` 和 `artifacts/visual` 中的 expected、actual、diff 与 trace。禁止用批量更新截图替代差异修复。

React 迁移状态以测试文件中的显式清单为准：两个设计系统 Fixture、主页及九模式交互已经通过；其余 26 个样稿状态仍须逐个完成 Fixture 和正式页面迁移后才能计入完成。
