玩家为什么会停下来

《从反馈到核心循环》· 2026/07/12 · 24 分钟

返回主页
永久只读

学习会话

原始学习和已有补充讨论分别归档；补充学习不修改最终 Review。

回想平台跳跃原型：玩家在第几分钟开始觉得重复？你看到了什么行为证据？
大概第三分钟。玩家还在继续跳，但已经不再尝试收集边缘金币。
这说明玩家已经不需要重新判断。问题更接近反馈没有改变下一次行动。
如果边缘金币临时提高跳跃高度，它是不是能改变路线判断？
关键不在奖励更强，而在玩家是否会因此重新比较路线；路线选择变化才是更直接的证据。

第一讲总结：玩家为什么会停下来

知识图谱

体验断点
├─ 行动变化：玩家是否仍需做新判断
├─ 反馈信息：系统是否带来新信息
└─ 目标推进：当前行为是否改变下一步追求

核心思想

玩家停下来往往不是因为看过相同画面，而是系统不再要求新的判断。

学习表现评价

你做得很好的地方

你从玩家不再收集边缘金币的行为证据，推出反馈没有改变下一次行动。
