# 共享 AI 富 Markdown 渲染设计

## 目标

所有 AI 输出页面共享同一个安全渲染边界，正确显示 GFM 表格、数学公式和代码块；Mermaid 流程图、关系图等图表围栏保留为可复制的安全代码回退，同时保留普通 Markdown 的高自由度。

## 设计

`packages/ui/src/ai-content.tsx` 是唯一的 AI Markdown 渲染入口。它使用 GFM 和数学语法插件解析表格与公式；代码围栏保持等宽代码块；`mermaid` 围栏标记为图表代码并安全回退为可复制的原始代码块，不阻塞整段回答。后续接入可选图表渲染器时不改变这一边界。

安全边界分为两层：原始 Markdown 不启用任意 HTML；KaTeX 生成的节点使用显式允许列表；Mermaid 使用严格安全模式、禁用自动启动和 HTML 标签。所有图表只由当前消息内容生成，不执行 AI 输出中的脚本或链接行为。

## 视觉行为

- 表格使用语义 `<table>`，表头、边框、单元格间距和横向滚动统一由 UI 样式控制。
- 数学公式使用 KaTeX 的 display/inline 样式，并在窄屏下允许横向滚动。
- Mermaid/流程图/关系图围栏显示为可复制的代码块，并保留语言标识，避免未安装图表运行时导致页面失败。
- 普通代码块保留语言标识和等宽字体，不转换成教学卡片。

## 验收

共享 UI 测试覆盖：GFM 表格（含压缩单行表格修复）、行内/块级数学公式、普通代码块、Mermaid 安全回退、危险 HTML 清理。课程创建、正式教学、Review、学习画像等既有调用点无需改写。
