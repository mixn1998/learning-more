# 正式课程函数图像渲染设计

## 目标

正式课程中的教学智能体可以在确有教学价值时，自由选择函数图像辅助讲解。系统把 AI 输出的声明式数学图像描述渲染为安全、可交互、响应式的二维或三维图像；图像是教学表达能力，不是每轮输出要求，也不改变现有教学状态机、观察模块或账本职责。

本切片提供完整的常用函数图像能力：

- 二维显函数与多函数对比；
- 二维参数方程、极坐标与隐函数；
- 离散点、定义域、关键点、切线和文字标注；
- 三维参数曲线与显式曲面；
- 二维向量场与自治微分方程相图；
- 失败时保留公式和声明文本，不阻断教学对话。

## 非目标

- 不执行 AI 生成的 JavaScript、HTML、SVG 或事件处理器；
- 不在本切片实现计算机代数系统、符号证明或自动求导；
- 不在本切片实现隐式三维曲面、动画、三维向量场或偏微分方程数值求解；协议保留后续扩展空间；
- 不要求教学智能体固定使用图像，也不以图像替代自然语言解释、推导和检测。

## 核心决策

采用 JSXGraph 作为统一数学绘图库。二维和三维共享同一交互与视觉边界，避免分别引入数据图表库和三维库导致两套行为。绘图库只接收系统构造的受控函数或数值序列，不接收可执行源码。

数学表达式使用受限 AST 解析：只允许数值常量、批准的变量、算术运算、括号和白名单数学函数。赋值、函数定义、数组、对象、属性访问、单位、导入、动态求值和多表达式块全部拒绝。不得使用 `eval`、`Function` 或直接执行模型文本。

JSXGraph 与表达式解析器通过动态导入进入独立前端 chunk。没有 `math-plot` 代码块的页面不下载绘图运行时。

## Markdown 接口协议

AI 通过 fenced code block 提交版本化 JSON：

````markdown
```math-plot
{
  "version": 1,
  "title": "函数与切线的关系",
  "view": {
    "type": "cartesian2d",
    "xRange": [-6, 6],
    "yRange": [-4, 10]
  },
  "series": [
    { "kind": "explicit", "expression": "x^2", "label": "f(x)" },
    { "kind": "explicit", "expression": "2*x-1", "label": "x=1 处的切线" }
  ],
  "annotations": [
    { "x": 1, "y": 1, "label": "切点" }
  ]
}
```
````

### 顶层结构

- `version`：固定为 `1`；未知版本按不可渲染处理。
- `title`：可选的学习者可读标题。
- `description`：可选的图像用途或结论说明，兼作无障碍描述。
- `view`：坐标系、可见范围和轴标签。
- `series`：至少一项、数量受上限保护的图像序列。
- `annotations`：可选关键点与文字标注。

### 视图类型

- `cartesian2d`：二维直角坐标；允许 `xRange`、`yRange`、`xLabel`、`yLabel`。
- `polar2d`：二维极坐标；允许半径范围和角度范围。
- `cartesian3d`：三维直角坐标；允许三个轴范围和标签。

范围必须是两个有限数值组成的递增区间。系统对绝对范围、跨度和采样密度设硬上限。

### 序列类型

- `explicit`：`y=f(x)`，可指定 `domain`。
- `parametric2d`：`x=f(t), y=g(t)`，必须指定参数范围。
- `polar`：`r=f(theta)`，必须指定角度范围。
- `implicit2d`：`f(x,y)=0`；允许 AI 使用 `equation` 表达等式，系统拆分两侧并转为差值。
- `points2d`：二维离散点，可用于样本、端点和数值结果。
- `parametric3d`：`x=f(t), y=g(t), z=h(t)`，必须指定参数范围。
- `surface3d`：`z=f(x,y)`，必须指定两个定义域。
- `vectorField2d`：二维向量函数 `(P(x,y), Q(x,y))`，允许受限的箭头密度与归一化显示。
- `odePhase2d`：二维自治常微分方程组 `dx/dt=P(x,y), dy/dt=Q(x,y)`，必须提供有限个初始点、积分区间和受限步长；系统使用有计算上限的 Runge–Kutta 积分生成相轨迹。

每项可携带学习者可读 `label`、颜色提示和有限的线型提示。颜色最终由系统主题调色板校正，保证对比度和不同序列可辨识。

## 模块边界

### `MathPlotContract`

负责从代码块文本解析、验证和规范化版本化 JSON。输出判别联合类型；不依赖 React 或 JSXGraph。未知元数据字段会被忽略且永不进入绘图库；未知协议版本、未知序列类型或必需字段缺失才按不可渲染处理。这样既不会让模型文本静默获得新的执行能力，也不会因无害的额外说明字段使整张图失效。

### `SafeMathExpression`

负责解析表达式 AST、校验节点和符号白名单，并生成只能接收已批准变量的数值函数。允许常用初等函数与常数，例如 `sin`、`cos`、`tan`、反三角函数、双曲函数、`exp`、`ln`、`log`、`sqrt`、`abs`、`floor`、`ceil`、`min`、`max`、`pi` 和 `e`。

结果必须是有限实数；复数、矩阵、单位或非数值结果作为该采样点的断点处理。表达式长度、AST 节点数和函数嵌套深度有硬限制。

### `MathPlot`

负责按视图和序列类型构造 JSXGraph board、曲线、曲面、点和标注。组件拥有图形运行时生命周期，卸载时释放 board；容器尺寸变化时自适应重排。

### `AiContent` 集成

共享 Markdown 边界识别 `language-math-plot` 代码块，懒加载 `MathPlot`。其他代码块、公式、表格和安全清理逻辑保持不变。正式课程消息已经通过 `AiContent` 渲染，因此不新增页面专用直通路径；Review 和历史课时中保存下来的同类图像也能正确重放。

### 教学智能体能力说明

正式教学上下文增加简短的能力说明与一个协议示例：当函数形状、变化、比较、切线、极值或空间曲面能明显帮助理解时，可以加入 `math-plot`；无需为了展示能力而画图。该说明不规定教学内容、回合结构或固定版式。

## 数据流

1. 教学智能体按需在自然 Markdown 中加入 `math-plot` 代码块。
2. 现有消息流原样保存 Markdown，不新增图像业务实体，不让图像描述进入教学账本控制面。
3. `AiContent` 识别代码块并把纯文本交给 `MathPlotContract`。
4. 合同通过后，`SafeMathExpression` 校验并编译每条表达式。
5. `MathPlot` 按类型创建二维或三维交互图。
6. Review、课时档案和历史回放继续消费同一份 Markdown，得到一致图像。

图像配置是消息内容的一部分；教学观察仍观察学习行为和证据，不为图像渲染增加模型调用。

## 交互与视觉规格

- 图像置于独立卡片，标题、图例、坐标区和说明具有清晰层级；
- 宽度随消息容器变化，二维使用适合阅读的固定纵横比，三维允许更高画布；
- 支持缩放、平移、复位和三维旋转；触屏与鼠标均可使用；
- 多曲线使用颜色、线型和图例共同区分，不能只依赖颜色；
- 图下提供可访问的系列名称与表达式摘要，容器具有学习者可读标签；
- 遵循现有纸张色、边框、圆角和间距变量，不引入独立视觉体系。

## 安全与稳定性

- AI 文本先通过 JSON 合同，再通过表达式 AST 白名单；两层均通过才能绘制；
- 禁止网络资源、任意脚本、DOM 注入、原始 HTML 和事件回调；
- 限制单图序列数、表达式长度、AST 节点数、二维采样点、隐函数分辨率和三维网格大小；
- 向量场限制网格密度；微分方程相图限制初始点数、积分步数、步长和坐标越界终止条件；
- 遇到渐近线、无定义区间和非有限值时切断曲线，避免错误连线；
- 单个图像失败只影响自身，不影响同一消息中的文字、公式或其他图像；
- WebGL 不可用时，三维图显示明确降级提示和表达式摘要，二维内容仍正常工作。

## 错误与降级

解析、验证、运行时加载或绘制失败时，显示“函数图像暂时无法渲染”状态，并保留标题、系列标签、原始表达式和可展开的原始代码。不得吞掉教学内容，不把内部异常或堆栈暴露给学习者。

开发环境记录稳定错误码：合同无效、表达式不安全、表达式不支持、绘图库加载失败、WebGL 不可用和渲染失败。错误码用于测试与诊断，不进入 AI 可见回复。

## 测试策略

### 合同与表达式单元测试

- 覆盖所有视图与序列判别分支，包括向量场和微分方程相图；
- 拒绝未知版本、未知序列类型、非法范围、超量序列和错误的视图/序列组合，并验证无害额外字段会被忽略；
- 验证常用函数、常数和多个变量；
- 拒绝赋值、属性访问、数组、对象、导入、动态求值、函数定义和超限 AST；
- 验证非有限值会形成断点而不是使整图崩溃。

### 组件测试

- `AiContent` 识别 `math-plot`，普通代码块行为不变；
- 有效合同懒加载图像组件；无效合同显示可读降级；
- 二维和三维分别创建并销毁 board；容器变化触发重排；
- 同一条消息中的 Markdown、KaTeX、表格和图像可以共存；
- 不安全 HTML 和脚本仍被清理。

### 正式课程回放测试

用真实 AI Markdown 样本覆盖显函数对比、隐函数、极坐标、三维曲面、向量场、微分方程相图、混合公式与图像、无效表达式和中断输出。测试正式课程、课时档案与 Review 的共享渲染结果，防止只在组件夹具中通过。

## 验收标准

- 正式课程无需刷新即可显示 AI 返回的二维和三维函数图像；
- 已批准的九类序列均能渲染，并能与 Markdown、公式和表格共存；
- AI 不包含图像时，首屏不加载绘图库；
- 任何模型输出都不能执行 JavaScript 或绕过表达式白名单；
- 无效或过重图像不会卡死整条课程消息，且学习者始终能看到可读降级内容；
- 历史课时和 Review 对同一 Markdown 的投影与正式课程一致。
