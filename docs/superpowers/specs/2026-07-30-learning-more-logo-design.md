# Learning MORE Logo 设计

## 目标

以“L 书架、M 书”为核心识别，将现有靶心式标志替换为更直接的学习品牌符号。

## 最终图形

- 采用视觉对比稿 C 的收边版本。
- `L` 表示书架立柱与底板，贴合书本左侧和底部。
- 展开的书页形成 `M`，作为视觉主体。
- 书架的最高点和最右端不得超出书本外轮廓。
- 不使用独立外框、序号、文字或复杂装饰。

## 视觉语言

- 深墨色：`#26323A`，用于书架。
- 陶土色：`#C87950`，用于书本。
- 浅陶土色：`#E9B69A`，用于简洁页纹。
- 浅色书脊：`#FFFAF5`。
- 图形采用圆角端点，在 30–38px 导航尺寸下保持清晰。

## 实施范围

- 替换 `apps/web/public/brand/learning-more-mark.svg`。
- 保持现有 `BrandIdentity` 组件、产品名称、导航布局和尺寸变量不变。
- 不引入位图资源或新的运行时依赖。

## 验证

- 检查 SVG 语法、视口和无障碍属性。
- 运行品牌组件相关测试和 Web 类型检查。
- 在产品导航栏实际尺寸下确认图形没有裁切、溢出或模糊。
