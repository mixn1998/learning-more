# 跨课程学习笔记设计

## 目标

学习者可以在正式课堂中连续记录多条独立笔记，并从首页进入统一笔记库，按学科和课程浏览、编辑或删除。每条笔记自动绑定保存时间、课程与课时，不依赖聊天消息或 Review。

## 交互

- 课堂对话区顶部承接实际学习时长、计时状态、继续学习、结束本课与返回课程大纲等操作。
- 右侧原学习时长卡片改为小型“本课笔记”区：输入框固定在上方，保存后的本课笔记按时间倒序显示在下方独立滚动列表中。
- 点击“保存笔记”或按 `Ctrl+Enter` 创建一条正式笔记；保存成功后清空输入框，失败时保留原文。
- 未提交文本仅按课时缓存在浏览器，刷新或短暂断线后可以恢复；它不属于正式笔记。
- 首页快捷操作区增加“学习笔记”入口。统一笔记页按“学科 → 课程”分组，并在条目中显示课时与保存日期。
- 每条正式笔记可以独立编辑或删除。课堂中编辑旧笔记不占用新笔记输入框。

## 数据与接口

学习笔记是独立聚合，字段为：

- `id`
- `markdown`
- `discipline`
- `courseId`、`courseTitle`
- `lessonId`、`lessonTitle`
- `createdAt`、`updatedAt`
- `resourceVersion`

课程、课时和学科元数据由服务端根据权威课程记录写入快照，客户端不能伪造。课程删除后笔记继续保留，并依靠快照保持可读和可分类。

接口：

- `GET /api/v1/learning-notes`
- `POST /api/v1/learning-notes`
- `PATCH /api/v1/learning-notes/:noteId`
- `DELETE /api/v1/learning-notes/:noteId`

列表接口支持 `courseId` 和 `lessonId` 过滤，默认按 `createdAt` 倒序。写操作使用资源版本避免覆盖并发编辑。

## 边界

- 笔记不写入教学对话、教学状态账本、Review、历史统计或用户档案。
- 首版不提供 AI 总结、标签生成、全文搜索、附件或富文本工具栏。
- 正式数据保存在本地服务；浏览器只保存未提交草稿。

## 异常与验证

- 创建失败保留草稿并提供重试。
- 编辑冲突提示重新载入，不静默覆盖。
- 删除失败保留原条目。
- 覆盖聚合版本、接口校验、课程元数据快照、课堂连续记录、首页入口、分组展示、编辑删除与草稿恢复测试。
