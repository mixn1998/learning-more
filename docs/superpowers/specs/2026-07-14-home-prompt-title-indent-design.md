# 主页课程创建标题缩进与基线设计

## 目标

调整主页课程创建区标题“模式名称 · 提示语”的水平位置，使它不再与下方输入框外边框严格左对齐，同时保持轻微、克制的层级差异。

## 设计

- 仅调整 `.prompt-head strong`，增加 `12px` 左侧内缩。
- 将 `.prompt-head` 的交叉轴对齐从居中改为基线对齐，使左侧标题与右侧模式徽标的文字基线稳定一致。
- 不移动输入框、输入文字、右侧模式徽标或整个标题容器。
- 不改变字号、颜色、行高、间距、响应式结构和交互行为。

## 验收标准

1. 标题起点比输入框外边框向右 `12px`。
2. 标题不会与输入框内文字起点对齐。
3. 标题与右侧模式徽标按文字基线对齐。
4. 桌面与窄屏布局均无换行、溢出或控件位移回归。
5. 现有主页测试通过，并通过浏览器截图检查。

## 实现范围

只修改 `apps/web/src/styles.css` 中 `.prompt-head` 与 `.prompt-head strong` 的现有规则；不改 React 结构和业务逻辑。
