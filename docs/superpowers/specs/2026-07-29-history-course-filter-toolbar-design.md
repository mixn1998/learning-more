# 历史课程筛选工具栏设计

## 目标

将历史课程的四个筛选项整合为一个紧凑工具栏，降低独立输入框带来的割裂感，同时保持筛选信息清晰、原生选择行为稳定。

## 视觉结构

- 四个筛选项共享浅色圆角底座，以细分隔线划分区域。
- 每项由小号弱化标签和清晰的当前值组成。
- 下拉框不再显示独立厚边框；悬停与键盘聚焦时仅强调当前分区。
- 非默认筛选值使用主题色提示筛选已生效。
- 排序与其他筛选保持同级，不增加额外图标或说明。

## 响应式与交互

- 宽屏保持四列单行。
- 中小屏自动排列为两列，手机端单列显示。
- 保留原生 `select`、现有状态与变更处理，不改变数据流和筛选规则。
- 焦点状态清晰可见，分区整体可点击。

## 验证

- 现有四项筛选仍能独立更新结果。
- 默认值与生效值具有明确但克制的视觉区别。
- 桌面、窄屏和键盘操作下布局与焦点状态正常。
