# 历史课程筛选工具栏设计

## 目标

将历史课程的四个筛选项整合为一个紧凑工具栏，降低独立输入框带来的割裂感，同时保持筛选信息清晰、原生选择行为稳定。

## 视觉结构

- 四个筛选项共享浅色圆角底座，以细分隔线划分区域。
- 每项由小号弱化标签和清晰的当前值组成。
- 单个选择项不呈现输入框、圆角框或聚焦框；悬停与键盘聚焦时仅使用底部细线和文字颜色提示。
- 非默认筛选值使用主题色提示筛选已生效。
- 排序与其他筛选保持同级，不增加额外图标或说明。

## 响应式与交互

- 宽屏保持四列单行。
- 中小屏与手机端自动排列为两列。
- 使用锚定在当前分区下方的自定义菜单，避免系统原生下拉样式。
- 菜单使用米白浮层、柔和阴影、淡分隔线和小圆点选中状态。
- 保留现有状态与变更处理，不改变数据流和筛选规则。
- 支持点击外部关闭，以及方向键、Home、End、Enter、Space、Escape 和 Tab。
- 焦点状态清晰可见，分区整体可点击。

## 验证

- 现有四项筛选仍能独立更新结果。
- 默认值与生效值具有明确但克制的视觉区别。
- 桌面、窄屏和键盘操作下布局与焦点状态正常。
