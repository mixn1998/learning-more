# 弹窗滚动隔离设计

## 问题

标准弹窗虽然限制了最大高度，但网格行仍按内容固有高度展开。内容区没有获得剩余高度，弹窗外层裁切内容后，滚轮继续作用于页面背景。

## 方案

- 标准弹窗采用 `auto minmax(0, 1fr) auto` 三行网格，使标题和底栏固定、正文占据剩余高度。
- 正文保持 `overflow-y: auto`，并通过 `overscroll-behavior: contain` 阻止滚动链传递。
- 标准弹窗存在时锁定页面背景滚动；关闭后由 CSS 状态自然恢复。
- 不修改课程选择卡片、创建课程表单或业务数据。

## 验收

- 鼠标位于课程选择弹窗正文时，滚轮只改变弹窗正文的 `scrollTop`。
- `window.scrollY` 在弹窗打开及滚动期间不变化。
- 标题和底栏保持可见，弹窗关闭后页面可正常滚动。
