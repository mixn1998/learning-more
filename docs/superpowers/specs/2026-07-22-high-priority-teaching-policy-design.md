# 高优先级教学方针设计

## 目标

把“避免审问式教学”从通用原则中的普通一句提升为所有互动教学回合的高优先级教学方针，使检测、纠偏、提问、案例和阶段推进都服务于用户理解，而不能退化为阅读理解式标准答案或在相似细节上原地盘问。

## Prompt 结构

完整教学 Prompt 的第一个策略区块改为：

```text
【教学方针（高优先级）】
以开放式的思辨研讨为核心教学原则，不预设任何阅读理解式的标准答案（严禁设计阅读理解式的课堂互动）。严谨应服务于用户的理解推进，纠偏后沿知识逻辑自然前进，而不是在原地打圈。
```

该区块位于现有 `【通用教学原则】`、边界、关闭、能力、当前阶段、深度、事实和控制协议之前。原通用原则中的旧句删除，完整新方针只出现一次，避免机械重复和 Prompt 噪声。

## 作用范围

该方针适用于所有课程模式、教学阶段和问题类型，不限于开放案例或组织设计课程。

- 提问不能预设依赖隐藏前提的标准答案。
- 纠偏完成后必须沿知识主线或用户已经形成的更深理解继续推进。
- 检测、支架和变式仍可使用，但不能围绕同一局部边界反复盘问。
- 现有领域状态机、掌握证据门槛、知识点责任和关闭规则保持不变。

## 实现边界

- 新增一个只负责渲染高优先级教学方针的纯函数，避免把优先级语义混入阶段策略。
- `renderTeachingConversationInput` 将该区块放在所有其他策略前。
- `renderTeachingCorePolicy` 删除被替换的旧句，其余通用原则不变。
- 不增加新的状态字段、Prompt 数值权重、AI 场景或运行时配置。

## 验收

1. 每个交互教学 Prompt 都包含完整新方针。
2. 新方针区块位于 `【通用教学原则】` 和所有其他策略区块之前。
3. Prompt 不再包含旧句“严谨应服务于理解推进；纠偏后沿知识逻辑自然前进，避免反复盘问相似细节。”
4. 新方针只出现一次。
5. 所有现有教学 Prompt、状态机和流式生成测试继续通过。
