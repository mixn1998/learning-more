# 课程热身中的知识地图定位设计

## 目标

课程热身不只提出暖场问题，还应帮助学习者理解：

- 本节课位于当前模块和整门课程的什么位置；
- 本节课对掌握当前模块、继续学习整门课程有什么作用；
- 当本节课是模块第一课时，当前模块在整门课程中的定位和意义；
- 当本节课也是整门课程第一课时，整门课程在所属学科或领域中的定位和意义。

这些内容是教学智能体的高层教学责任，不是固定的输出清单。智能体可以根据课程目标、知识关系和学习者背景，自由决定叙述顺序、展开程度和表达方式。

## 设计原则

### 提供事实，不规定话术

系统向教学智能体提供可靠的知识地图上下文，包括：

- 学科或领域；
- 整门课程的目标；
- 当前模块及其课节构成；
- 当前课节在模块和课程中的位置；
- 当前课节与前后课节的知识关系；
- 当前课节是否为模块第一课、是否为课程第一课。

系统不要求固定标题、固定段落、固定句式、固定篇幅或逐项复述这些事实。定位与意义应自然服务于本次热身，而不是成为机械的课程介绍。

### 保持现有热身流程

- 开场回复先自然建立必要的知识地图定位，再以一个暖场问题收束并等待学习者回应。
- 不显示“课前热身”标题，也不显示第一个知识点标题。
- 热身阶段不展开第一个知识点，不推进教学账本中的知识点状态。
- 学习者作出一次回应后，无论回答质量如何，下一条助手消息都作出必要反馈并进入第一个知识点。
- 不追加第二个暖场问题，也不要求学习者发送无效消息推进课程。

### 分层扩展，而非硬性模板

普通课节主要说明本课在当前模块和整门课程中的作用。

模块第一课可以自然扩大视野，说明模块要解决的核心问题、它承接什么以及为后续建立什么基础。

课程第一课可以进一步说明整门课程在所属学科或领域中的位置，但仍由教学智能体判断怎样组织最清楚，不要求依次完成固定栏目。

## 结构与数据来源

教学上下文在现有课程信息之外增加一个可选的知识地图位置对象。该对象由已激活大纲及其来源候选版本构建，不从生成文本或旧课节的 `outlineVersionId` 猜测模块归属。

建议包含以下语义字段：

- `discipline`
- `courseGoals`
- `courseLessonIndex` 与 `courseLessonCount`
- `moduleId`、`moduleTitle`
- `moduleLessonIndex` 与 `moduleLessonCount`
- `moduleLessons` 的简洁标题与目标
- 当前模块前后的相邻模块标题
- `isFirstLessonInModule`
- `isFirstLessonInCourse`

课节匹配优先使用候选大纲中的稳定语义标识；对于被冻结并继承到新版大纲、但实体 ID 与候选 ID 不同的课节，沿用现有标题语义匹配规则建立归属。只有在可以可靠定位时才提供模块事实；无法定位时保留课程与当前课节事实，不编造模块关系。

## 提示词职责

热身阶段的高层指令调整为：

> 在提出暖场问题前，结合提供的知识地图事实，自然帮助学习者理解本节课在当前模块和整门课程中的位置及学习意义。若它是模块或课程的起点，可相应扩大到模块或学科层级。根据实际教学需要自由组织，不使用固定栏目或机械复述。最后只提出一个能够连接本课目标与学习者已有经验的暖场问题，并等待回应。

原有可能被理解为“整条回复只能包含一个问题”的表述应删除或改写。以下边界继续保留：

- 只有一个暖场问题；
- 本轮不展开知识点；
- 本轮不推进知识点状态。

## 数据流

1. 读取当前课程、当前课节和已激活大纲版本。
2. 从已激活大纲的结构化候选数据取得学科、课程目标、模块及课节顺序。
3. 将正式课节映射到当前模块，并计算课程与模块位置事实。
4. 把位置事实写入教学事实上下文。
5. 热身策略仅声明高层教学责任和流程边界，由教学智能体自由生成定位说明与一个暖场问题。
6. 学习者回应后沿用现有状态机进入第一个知识点。

## 兼容与失败处理

- 知识地图位置对象为可选字段，旧课程和缺少结构化候选数据的课程保持可用。
- 缺少可靠模块映射时，不输出推测的模块位置；教学智能体仍可使用课程目标、当前课节和相邻课节完成较弱的定位。
- 不修改教学账本的阶段、观察、推进、计时或失败恢复语义。
- 不改写既有课程对话，也不重投影 Review。
- 当前已激活的大纲版本继续作为唯一权威来源，旧版已完成课节的实体归属不覆盖新版模块划分。

## 测试策略

测试聚焦事实供给和流程契约，不机械评价自然语言：

- 课程普通课节能够取得课程、模块和课节位置事实；
- 模块第一课与课程第一课的标志计算正确；
- 冻结课节在新版大纲中的模块归属正确；
- 缺少候选结构时安全降级，不生成错误模块信息；
- 热身提示词包含知识地图定位的高层责任，但不包含固定输出模板；
- 开场仍只产生一个暖场问题，不显示知识点标题，不推进知识点状态；
- 一次学习者回应后仍直接进入第一个知识点；
- 既有教学账本与继续讲解流程的相关回归测试保持通过。

## 验收标准

- 热身能够让学习者理解“现在学到哪里、为什么此时学这一课、它将支持什么”。
- 模块首课和课程首课能够在需要时提供更高层定位。
- 不出现固定的“课程定位／模块定位／课节定位”栏目或逐项播报。
- 不因新增定位说明产生第二个暖场问题或延迟进入第一个知识点。
- 模块归属以当前激活大纲为准，冻结课节不会回退到旧版模块划分。
