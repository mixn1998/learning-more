# 结束课节弹窗滚动设计

## 目标

当未完成节点较多时，结束课节弹窗仍完整限制在当前视口内，用户可以滚动查看全部节点，并始终能够操作“继续学习”或“确认放弃课节”。

## 交互与布局

- 遮罩层保持现有居中弹窗行为。
- 弹窗最大高度不超过当前视口扣除遮罩内边距后的可用高度。
- 标题、闭环说明和底部操作区保持固定可见。
- 未完成节点列表作为弹窗中唯一的纵向滚动区域。
- 内容不足一屏时不显示无意义的滚动条，也不改变现有视觉尺寸。
- 小屏幕沿用同一结构，滚动区域自动压缩以保证底部按钮可达。

## 实现边界

- 只调整结束课节弹窗的结构类名和 CSS，不修改结束、放弃或 Review 的业务逻辑。
- 不改变按钮文案、节点内容、接口或公共组件。
- 使用 flex/grid 的剩余空间分配和 `overflow-y: auto`，避免依赖固定像素高度。

## 验证

- 未闭环且节点列表较长时，弹窗不超出视口，列表可滚动到底。
- 底部按钮在列表滚动过程中保持可见。
- 已闭环的短内容弹窗维持正常尺寸，不产生多余滚动条。
- 现有结束与放弃操作测试继续通过。
