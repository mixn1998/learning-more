# 课程头部单段介绍文本设计

## 1. 背景与问题

正式课程页面当前尝试把确认版大纲 H1 与第一个模块 H2 之间的全部 Markdown 作为课程介绍直接渲染。该区段可能同时包含课程定位、学习路径、教学方法、哲学旁注、预计时长和学习周期，因此页面会把大纲前言区几乎原样搬入课程头部。

课程头部需要忠实表达课程定位，但它不是大纲阅读器。这里应展示一整段自然、完整的课程介绍文本，而不是复刻大纲结构，也不把前言区拆成多项展示字段。

## 2. 目标

- 从已保存的确认版 Markdown 大纲中选择真正的课程介绍自然段。
- 将选中的内容转换为一整段普通文本。
- 保留原段落的完整语义，不设置机械字数上限，不在句中截断。
- 明确排除学习路径、教学方法、哲学旁注、预计时长和学习周期等说明块。
- 旧大纲没有可识别介绍时提供稳定的一句话兜底。

## 3. 非目标

- 不把大纲前言拆成介绍、路径、方法、旁注、时长等结构化字段。
- 不在课程头部的其他位置补充展示被排除的信息。
- 不增加 AI 调用、异步后处理、后端字段、共享契约或存储迁移。
- 不改动大纲原文，也不改变模块和课节投影逻辑。
- 不对介绍文本施加固定字数或固定句数模板。

## 4. 方案选择

采用“语义块选择”方案。

系统只在课程 H1 后、第一个 H1/H2 章节前的前言区中寻找课程介绍。它选择一个完整自然段，清理展示标记并输出单段文本，不把多个不同职责的段落机械合并，也不调用 AI 重新摘要。

未采用的方案：

- 多段机械合并：会再次把学习路径、方法和时长混入介绍。
- AI 即时改写：会增加页面延迟、成本和结果波动，并使同一确认版大纲的展示不稳定。

## 5. 解析规则

### 5.1 候选范围

候选内容仅来自：

1. 第一个一级标题 H1 之后；
2. 第一个后续一级或二级标题之前。

模块、课节和后续章节内容不得回流到课程介绍。

### 5.2 块划分

以前言区中的空行划分自然块。解析时忽略：

- Markdown 标题；
- 无序和有序列表；
- 表格；
- 引用块；
- 围栏代码块；
- 分隔线；
- 仅包含标签、箭头序列或统计数字的展示块。

### 5.3 选择优先级

1. 优先选择以“课程介绍”“课程简介”“课程概述”或“导语”明确标注的正文块；正文可以与标签同块，也可以紧随独立标签块，标签本身不进入最终文本。
2. 没有明确标注时，选择第一个完整的叙述性自然段。叙述性自然段必须包含连续语句，且不能主要由符号、数字、标签或箭头序列构成。
3. 候选块命中排除规则时继续寻找下一个候选块，而不是把它与介绍合并。

### 5.4 排除规则

以下内容不作为课程介绍，也不转换为其他头部展示信息：

- 学习路径、学习路线、教学路径、思维路径、每课流程；
- 教学方法、学习方法、课程组织方式；
- 哲学旁注、课程旁注、方法论旁注；
- 预计时长、总学习时间、每周安排、学习周期；
- 课节数量、模块数量等统计说明。

识别以块级语义和常见引导语为依据，不因普通课程介绍偶然出现“时间”或“方法”等单字就整段删除。

### 5.5 文本转换

选中自然段后：

- 合并段内换行和连续空白；
- 保留链接的可见文字，移除链接地址；
- 移除粗体、斜体、行内代码等 Markdown 展示符号；
- 保留原有标点和完整语义；
- 不按字符数截断，不拼接其他自然段。

输出示例：

```text
这是一门以一元微积分为主线的系统入门课。课程先给出极限、导数和积分的完整地图，再逐层深入定义、推导与证明。
```

## 6. 兜底规则

当前言区不存在合格的课程介绍时，使用解析后的课程标题生成最小兜底：

```text
这是一门关于“微积分：从直观变化到严格推导”的课程。
```

兜底不引用模块名、课节名、关键词、预计时长或知识点，以免重新生成机械拼接文本。

## 7. 组件与数据流

```text
确认版 outlineMarkdown
  → 大纲 Markdown 投影器定位前言区
  → 课程介绍自然段选择器
  → Markdown 行内标记清理与空白归一化
  → introductionText: string
  → FormalCourseView 使用普通 <p> 渲染
```

投影接口只暴露一个课程介绍字符串，例如：

```ts
type ResolvedCourseIntroduction = Readonly<{
  title: string;
  introductionText: string;
}>;
```

`introductionText` 是显示视图，不是新的持久化业务字段。

## 8. 页面表现

- 课程标题继续使用现有标题解析结果。
- 标题下只显示一个介绍段落。
- 不使用 Markdown 富文本组件渲染课程介绍，避免大纲中的粗体块、列表和多段间距进入头部。
- CSS 允许文本自然换行；不使用固定行数截断。
- 模式和课节数徽章保持现状。

## 9. 测试与验收

### 9.1 解析测试

- 前言区包含“课程介绍 + 学习路径 + 哲学旁注 + 预计时长”时，只输出课程介绍段落。
- 明确标注的课程介绍优先于未标注叙述段。
- Markdown 粗体、链接和行内代码转换为可读纯文本。
- 前言区仅有学习路径或时长时，使用标题兜底。
- 不设置字符数截断，长但完整的介绍段保持完整。

### 9.2 组件测试

- 课程头部只出现一个介绍段落。
- 学习路径、教学方法、哲学旁注和预计时长文本均不出现。
- 介绍使用普通段落元素，不产生列表、引用或额外标题。

### 9.3 回归测试

- 模块分组、课节标题和课节一句话摘要保持不变。
- 历史大纲仍可在版本查看器中完整渲染 Markdown；只限制课程头部投影。

## 10. 完成标准

- 截图所示微积分课程头部只显示课程介绍自然段。
- 大纲中的学习路径、教学方法、哲学旁注和预计时长不再进入课程头部。
- 没有字数硬截断，没有额外 AI 调用，没有契约或存储变更。
- 相关解析、组件、类型检查和回归测试全部通过。
