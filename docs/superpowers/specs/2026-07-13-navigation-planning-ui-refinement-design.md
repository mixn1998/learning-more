# 课程导航、排期与界面精简设计

> 日期：2026-07-13  
> 状态：已确认，待实施  
> 作用范围：Learning MORE 当前 UI 样稿及后续 React 正式实现

## 1. 目标

统一课程继续入口、课程规划与计划流交互，减少不必要的跳转、弹窗和说明性界面元素，并修正现有模拟页面中的计算与视觉不一致。

## 2. “继续学习”课程选择

### 2.1 路由规则

- 查询全部未关闭正式课程。
- 未关闭课程为零时，主页“继续学习”进入稳定空状态，并提供返回主页或创建课程入口。
- 只有一门未关闭课程时，直接进入该课程的正式课程大纲。
- 有两门及以上未关闭课程时，打开“选择课程”窗口。

### 2.2 选择课程窗口

- 课程按最近学习时间降序排列；从未学习的课程排在所有已有学习活动的课程之后，再按创建时间降序排列。
- 含“学习中”课节的课程使用轻量边框、状态标识或背景强调，但不改变排序规则。
- 点击课程卡统一进入对应正式课程大纲。
- 窗口不提供“继续当前课节”按钮，不直接进入课节会话，不处理课节级跳转冲突。
- 关闭窗口后留在原页面，不改变课程或课节状态。

### 2.3 前端模拟

- 样稿提供至少一门课程和多门课程两种可测试数据分支。
- 多课程窗口必须支持打开、关闭、课程排序检查与卡片导航。
- 只有真正依赖持久化查询的部分才显示模拟提示；已在样稿内定义的数据交互必须完整执行。

### 2.4 正式课程大纲内切换课程

- 未关闭课程达到两门时，正式课程大纲右上角在“返回主页”和“修改大纲”之间显示“切换课程”。
- 点击“切换课程”复用主页的“选择课程”窗口及同一排序规则。
- 当前课程显示“当前课程”标识且不可重复选择；点击其他课程卡进入对应正式课程大纲。
- 只有一门未关闭课程时隐藏“切换课程”，避免无效操作。
- 课程关闭后不显示“修改大纲”；是否显示“切换课程”仍由其他未关闭课程数量决定。

## 3. 七天侧栏

- 每张日期卡将周几、今天标记和日期放在同一行，例如：`周日 · 今天　07/12`。
- 周几、今天标记和日期统一字号、字重、行高与基线，不再形成上下两级视觉标题。
- 课节名称放在日期行下方；无课节时显示“暂无安排”或对应页面的稳定空状态。
- 七张日期卡继续在桌面端可视高度内等分铺满，不出现左栏内部滚动条；左栏粘性跟随并与右侧底边对齐。
- 移动端恢复自然单列与自然高度。
- 点击日期仍按既有规则筛选右侧课程列表。
- 主页周历卡只展示有限预览：课节名保持单行省略；内容超出容量时保留前几节并在末行显示“另有 N 节”。
- 点击日期卡或“另有 N 节”后，下方当日学习列表展示该日全部课节；周历卡本身不出现内部滚动条。

### 3.1 学习日历内容溢出

- 月历日期格中的课节名称保持单行省略，默认最多展示两节。
- 超过两节时显示“另有 N 节”，日期格不增高且不出现内部滚动条。
- 点击日期格后，右侧日期详情区展示该日全部已完成课节及完整标题。

## 4. 课程规划卡片

### 4.1 紧凑布局

- 课节标题与 `课程名 · 日期/排期状态 · 预计时长` 位于同一横向信息区。
- 操作区右对齐，桌面端与主信息区保持同一视觉行；空间不足时按完整信息块自然换行，不压缩文字或遮挡控件。
- 状态标签和主题标签仅在能表达真实状态或分类时保留，不为维持版式重复展示。
- 卡片高度由内容自适应，使用固定的文字行高、段间距和内边距，不设置会截断动态内容的固定高度。

### 4.2 原生日期选择

- 未排期课节只显示“点击安排学习日期”，不显示空日期格式，不显示“取消排期”。
- 点击提示文字直接调用浏览器原生日期选择器，不打开二次弹窗或自定义日历弹层。
- 用户选定日期后，卡片原位显示具体日期、“取消排期”和“预览”。
- 已排期课节点击日期可再次调用原生日期选择器并完成改期。
- 点击“取消排期”后恢复未排期状态，只显示“点击安排学习日期”和“预览”。
- 取消原生日期选择时不改变原排期状态。
- 日期选择、改期和取消排期只更新样稿前端状态；正式实现通过排期应用服务持久化。

## 5. 计划流学习时长

### 5.1 统一时长

- 当前版本对全部已选学习日使用同一个“每日目标时长”，不支持按星期分别设置。
- 保留 15、30、45、60、90 分钟快捷选项。
- 增加“自定义时长”，允许输入超过 90 分钟的正整数分钟数。
- 自定义值按 15 分钟步进；最小 15 分钟。界面不设置武断的低上限，但对异常超大值提供非阻断提示。

### 5.2 每周预计时长

- 每周预计时长实时计算为：`选中学习日数量 × 每日目标时长`。
- 切换任意学习日、修改快捷时长或修改自定义时长后立即重新计算。
- 展示统一使用可读格式：不足 60 分钟显示分钟；达到 60 分钟显示“X 小时 Y 分钟”，整小时省略零分钟。
- 例：7 天 × 90 分钟显示“预计每周 10 小时 30 分钟”，不得保留旧值。
- 没有选择学习日时显示“预计每周 0 分钟”，并在进入下一步时提示至少选择一天。

## 6. 历史统计指标卡

- 移除“累计实际学习时长”卡片的 `primary` 视觉差异。
- 四张统计指标卡统一使用白底、相同边框、圆角、内边距和阴影规则。
- 指标本身不通过底色建立隐含优先级；当前统计范围由上方筛选按钮表达。
- 指标值、标题和辅助说明继续保留层级差异。

## 7. 说明性文案清理

- 从正式课程大纲删除“推荐但不锁课”胶囊。
- “推荐但不锁课”只作为规则文档中的产品原则保留；具体推荐仅在对应课节显示“推荐下一课”。
- 全量排查当前最终稿中的设计说明、样稿说明、实现说明和占位解释，不把它们作为产品内容展示。
- 删除标准：文字只解释系统设计、实现方式或开发约束，且不帮助用户理解当前真实状态或完成当前操作。
- 保留标准：真实状态、必要操作提示、错误恢复提示、空状态和用户决策所需信息。
- 删除说明性文字后不添加替代占位内容。

## 8. 相邻规则保持不变

- 所有确认版课节自由进入，系统推荐但不锁课。
- 课程卡选择只进入正式课程大纲，不直接进入具体课节。
- 日期筛选与其他筛选继续按已确认的互斥规则运行。
- 课程规划预览不创建学习会话；排期和改期也不创建学习会话。
- 课程状态、课节状态和 Review 规则不因本次视觉与导航调整而改变。

## 9. 失败与边界处理

- 未关闭课程查询失败：保持当前页面，显示可重试错误，不猜测目标课程。
- 原生日期选择器不可用：日期控件仍允许键盘输入合法本地日期；非法值不提交。
- 自定义时长为空或非法：保留上一个有效值并显示字段级提示。
- 多课程存在相同最近学习时间：按课程更新时间、创建时间和稳定课程 ID 依次排序，保证顺序稳定。
- 目标课程在点击前已关闭：提示状态已变化并刷新可选课程列表。

## 10. 验收范围

- 主页“继续学习”覆盖 0、1、2+ 门未关闭课程。
- 多课程列表排序正确，含“学习中”课节的课程视觉突出，卡片统一进入大纲。
- 正式课程大纲在存在多门未关闭课程时可打开同一选择窗口并切换课程；单课程时不显示无效入口。
- 七天侧栏日期行统一且七卡等分，无左栏内部滚动。
- 主页周历和学习日历的课节标题溢出时显示“另有 N 节”，完整列表分别由下方当日列表和右侧日期详情承接。
- 课程卡在桌面、平板和移动端无文字遮挡或控件变形。
- 未排期、选择日期、改期、取消排期和预览形成完整前端闭环，无二次日期弹窗。
- 计划流周时长随学习日和每日时长实时变化，自定义时长超过 90 分钟可用。
- 历史统计四张指标卡统一白底。
- “推荐但不锁课”及同类说明性产品外文案从页面删除。
- 页面冒烟、交互回归、控件接线、控件几何、模块几何、文字间距和三视口视觉完整性测试全部通过。

## 11. 规格自检

- 无待定字段、占位规则或未定义按钮。
- 课程选择与课节继续入口边界明确：只进入课程大纲。
- 日期选择不使用自定义弹窗，和现有排期状态转换一致。
- 每日时长为统一值，自定义时长和周总时长计算口径明确。
- 本次改动不扩张到课程状态机、Review 或 AI 教学策略。
