# 未确认建档会话永久删除设计

## 目标

在学习档案创建工作台提供“删除草稿”入口。用户二次确认后，永久删除整个未确认建档会话及其候选大纲、上传材料和生成草稿，然后返回主页。

## 交互

- 删除入口位于建档工作台候选大纲面板底栏左侧，使用危险操作样式。
- 主页“继续学习”弹窗中的每张未确认草稿卡片也直接显示“删除草稿”；该按钮与“继续完成大纲建档”分离，点击删除不得触发建档导航。
- “选择课程”弹窗固定底栏提供“返回主页”，点击后关闭弹窗并回到当前主页；长列表滚动时该操作保持可见。
- 点击后显示二次确认弹窗，明确列出会被永久删除的内容且说明不可恢复。
- 删除期间禁用重复提交；失败时保留当前工作台并在确认弹窗显示错误。
- 工作台删除成功后清理当前页面的会话草稿缓存并返回主页；主页删除成功后立即从草稿列表移除对应卡片并保持课程选择弹窗打开。
- 已确认并生成正式课程的会话不显示删除入口，服务端也拒绝按草稿删除。

## 数据边界

单个本地事务删除：

- outline session 聚合；
- 该 session 的 candidate outline versions；
- 该 session 的 uploaded materials；
- owner 或候选版本关联到该 session 的 generation tasks；
- 上述记录引用且未被其他记录引用的 draft/finalized artifacts。

正式课程、学习记录、历史统计及其他会话数据不在范围内。

## API

`DELETE /api/v1/outline-sessions/:sessionId`，要求命令头和 `If-Match`。成功返回被删除的 `outlineSessionId` 与 `deletedAt`；不存在、版本冲突或已确认会话返回现有 Problem Details 错误。
