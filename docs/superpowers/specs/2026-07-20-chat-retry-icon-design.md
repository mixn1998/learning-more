# 对话重试图标优化

## 目标

将对话消息底部使用字体字符 `↻` 的重试入口，替换为稳定、轻量且与消息操作区一致的图标按钮。

## 设计

- 使用内联 SVG 绘制 16px 逆时针回转箭头，不依赖操作系统字体。
- 按钮保持 28×28px 圆形点击区，默认透明背景与弱边框。
- 悬停时使用浅色强调背景；键盘焦点显示清晰但不过重的焦点环。
- “重新发送”和“重新生成”共用同一图标组件，继续通过 `aria-label` 与 `title` 区分语义。
- 不改变重试业务逻辑、消息状态或可用条件。

## 验收

- AI 回复与用户失败消息的重试入口显示一致的 SVG 图标。
- 图标不再受字体字形影响，按钮不出现大号独立操作块的视觉感受。
- 鼠标、键盘和辅助技术仍可正常使用。
- 相关组件测试不再断言字符 `↻`，改为验证可访问名称和 SVG 图标存在。
