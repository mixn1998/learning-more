# 课程永久删除功能规则

## 1. 定义

“删除课程”是针对单个正式课程的不可逆级联删除操作。删除成功后，该课程不再存在于课程档案、学习记录、课程表、历史统计或学习画像的数据来源中。

该操作不同于课程关闭：关闭保留全部课程档案并锁定内容；删除会永久清除课程及其关联数据。

## 2. 入口与交互

- 入口位于正式课程大纲页的危险操作区，不与“返回主页”“切换课程”“修改大纲”等普通导航动作混排。
- 允许删除进行中、可关闭或已关闭的正式课程。
- 点击“删除课程”后打开风险确认弹窗，明确说明删除不可恢复及受影响数据范围。
- 弹窗只提供“取消”和危险主操作“永久删除”；不要求输入课程名称或额外文本。
- 用户点击“永久删除”后，按钮进入提交中且禁止重复提交；完成后跳转主页，并显示“课程及关联记录已永久删除”的结果提示。
- 若删除失败，保留课程及现有数据，不进行局部删除；弹窗展示失败状态并允许重新尝试或取消。

## 3. 级联删除范围

成功删除 Course 后，必须在同一删除事务中移除其全部关联数据：

- Course 本体、来源关系和课程状态；
- 确认版大纲、历史大纲版本、课节定义与模块映射；
- 学习会话、补充学习会话、消息、会话写入租约与学习计时区间；
- 课时 Review、课程主题总 Review、关闭输入快照及生成任务；
- 已放弃课节的阶段 Review 与恢复导航数据；
- 课程表排期、计划流条目、待规划/已安排/已逾期派生投影；
- 阅读研讨材料的课程引用、章节映射与解析快照引用；仅当文件或解析产物不再被任何其他课程引用时，才可回收其物理资源；
- 课程在主页、继续学习、课程切换、历史课程清单和全部 UI 投影中的索引。

## 4. 历史统计与学习画像

课程删除必须同时撤销由该课程产生的底层学习事实，而非仅隐藏展示：

- 删除该课程的完成课节事实、实际学习时长、活跃日、日历课节、课程关闭事实与 Review 来源引用；
- 历史统计、学习日历和课程数等投影从剩余事实重新计算；
- 学习画像候选证据、来源组、证据链和已生成画像中所有仅由该课程支持的内容均失效；
- 删除事务完成后触发学习画像重算。重算失败不回滚已完成的课程删除，但画像页面必须显示“正在更新”或“更新失败，可重试”，且不得继续展示已删除课程的证据或结论；
- 若一个画像结论同时被其他独立来源支持，仅移除该课程对应来源，不删除剩余有效证据。

## 5. 一致性与恢复

- 课程主数据、学习记录、排期与统计事实必须以原子事务或可恢复删除任务完成，禁止出现课程已消失但学习事实仍可被读取的稳定状态。
- 删除命令使用幂等键：重复提交返回同一最终结果，不重复扣除统计或重复触发画像重算。
- 删除开始后，课程会话立即失去写入权，计时停止；任何后到消息、Review 写入或计划流更新必须被拒绝。
- 删除成功后不可恢复，也不保留回收站、软删除或隐藏副本。
- 任何关联资源无法安全删除时，整个删除操作失败并保持删除前的可读状态；不得以部分成功形式向用户宣告删除完成。

## 6. UI 验收

- 正式课程大纲页展示独立危险操作入口。
- 风险弹窗准确列出课程档案、学习记录、Review、排期、历史统计和学习画像将受影响。
- 取消不改变任何数据；确认后课程从当前页面、主页、课程切换和历史统计/日历样稿中消失。
- 删除后不显示已删除课程的推荐、继续学习入口、课程主题总结、学习画像证据或统计贡献。
