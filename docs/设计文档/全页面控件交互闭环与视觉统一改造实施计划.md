# Learning MORE 全页面控件交互闭环与视觉统一改造实施计划

> **For agentic workers:** 按任务顺序执行；每个任务必须先建立失败证据，再实现，再通过对应浏览器检查。当前项目不是 Git 仓库，不执行虚构提交；每个任务以测试输出和验收矩阵勾选作为审查关口。

**Goal:** 让 `docs/UI视觉预览` 中全部 27 个当前 HTML 样稿的每个控件都形成可观察的前端模拟闭环，并统一字体、行高、留白、滚动和课节白底规则。

**Architecture:** 新增一个只服务静态样稿的共享交互运行层，负责 Toast、确认弹窗、模拟异步和 ARIA 状态；复杂业务交互仍由各功能域页面或现有域脚本管理。自动化审计按“页面—控件—动作—结果”验证，不再以页面能打开作为完成标准。

**Tech Stack:** HTML5、CSS Custom Properties、原生 JavaScript、Node.js、Playwright、Python `http.server`。

## Global Constraints

- 所有当前样稿位于 `D:\workspace\Growth OS\Learning MORE\docs\UI视觉预览`。
- `01–07` 产品页面只呈现产品界面；样例说明和调试场景不进入用户界面。
- 所有控件必须产生导航、选择、筛选、弹窗、本地编辑、模拟异步或明确禁用中的一种结果。
- 真正依赖 AI、文件解析和持久化的动作只做明确模拟，不伪装真实后端写入。
- 九种模式入口文案只用于展示，不进入隐藏 Prompt。
- 周历和学习日历中的课节块统一白底；模式色仅用于外层日期卡、选中状态和身份标识。
- 成功、警告、错误、已放弃和只读继续使用全局状态色。
- 不修改已确认的课程状态机、Review 权威性、排期规则和画像证据规则。
- 必要正文不得小于 12px；正文 14px/1.65，说明 12px/1.55，控件 13px/1.35。
- 测试视口固定为 1440×1000、1024×768、390×844。
