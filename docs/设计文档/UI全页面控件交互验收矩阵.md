# UI 全页面控件交互验收矩阵

> 范围：`docs/UI视觉预览` 当前 27 个 HTML 页面。产品页必须呈现纯产品界面；设计策略、样稿说明和调试场景只允许出现在 `00-设计系统` 或设计文档中。

## 统一验收口径

- 每个可点击控件必须产生可观察结果：状态变化、内容变化、弹窗、导航或明确的模拟处理反馈。
- 只有真正依赖 AI、后台事务或持久化的动作可以显示“模拟处理”；普通筛选、选择、步骤切换不得用提示代替实际交互。
- 所有弹窗支持关闭、取消和键盘 Escape；关闭后焦点回到触发控件。
- 桌面 `1440×1000`、平板 `1024×768`、移动端 `390×844` 均不得发生文字遮挡、控件重叠或双重内部滚动。
- 周历、学习日历中的课节内容块统一白底；模式色只用于日期卡外层、选中态和模式身份。
- 产品页不得出现“样稿说明”“固定大弹窗四步向导”“当前模式只提供整体体验语境”等设计解释。
- 视觉回归分为四个独立关口：控件几何、模块几何、文字排版、间距与边界；四项均须覆盖桌面、平板和移动端。

## 当前自动检查

- `00-设计系统/tests/run-ui-audit.mjs`：页面外壳、产品页纯度和禁用说明文案。
- `00-设计系统/tests/run-page-smoke.mjs`：主页、计划流和运行中心实际加载、控制台错误与首屏状态。
- `00-设计系统/tests/run-control-geometry.mjs`：按钮、标签、Tab 的异常拉伸、换行和文字溢出。
- `00-设计系统/tests/run-module-geometry.mjs`：模块裁切、重叠、横向溢出和关键左缘对齐。
- `00-设计系统/tests/run-typography-spacing.mjs`：字号、行高、点击区域、内边距与文字边界。

矩阵状态只在对应页面完成三视口浏览器回归后改为“通过”。
