# UI 全页面控件交互验收矩阵

> 范围：`docs/UI视觉预览` 当前 27 个 HTML 页面。产品页必须呈现纯产品界面；设计策略、样稿说明和调试场景只允许出现在 `00-设计系统` 或设计文档中。

## 统一验收口径

- 每个可点击控件必须产生可观察结果：状态变化、内容变化、弹窗、导航或明确的模拟处理反馈。
- 只有真正依赖 AI、后台事务或持久化的动作可以显示“模拟处理”；普通筛选、选择、步骤切换不得用提示代替实际交互。
- 所有弹窗支持关闭、取消和键盘 Escape；关闭后焦点回到触发控件。
- 桌面 `1440×1000`、平板 `1024×768`、移动端 `390×844` 均不得发生文字遮挡、控件重叠或双重内部滚动。
- 周历与学习日历日期卡内课节采用无背景、无边框的紧凑文字行；模式色只用于日期卡外层、选中态和模式身份。
- 产品页不得出现“样稿说明”“固定大弹窗四步向导”“当前模式只提供整体体验语境”等设计解释。
- 视觉回归分为四个独立关口：控件几何、模块几何、文字排版、间距与边界；四项均须覆盖桌面、平板和移动端。

本轮补齐：未关闭课程的单/多课程路由与大纲内切换；日期卡溢出摘要；课程规划锚定日期选择层和直接取消排期；计划流统一/自定义时长与实时周预计；统计指标卡等权白底；“推荐但不锁课”等设计说明从产品页面移除。
