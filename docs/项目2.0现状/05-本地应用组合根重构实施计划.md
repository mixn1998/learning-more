# 本地应用组合根重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `local-application.ts` 从 2,700 行跨模块编排中心重构为薄外部入口和纯组合 assembly，同时保持全部功能、HTTP 合同、恢复语义与前端交互不变。

**Architecture:** `LocalApplication` 保持一个稳定外部 Interface，内部按 Generation、EventFacts、Profile、Course、Learning、Planning、Review、Insights、Home 和 Readiness 划分深 Module。每个 Module 直接产生其 owning RouteOptions；assembly 只按既有顺序创建 Module、调用恢复/启动/关闭并浅合并 `ServerDependencies`。

**Tech Stack:** TypeScript 5.9、Node.js 24、Fastify、Vitest、LocalFile Repository、pnpm、现有 architecture checker

## Global Constraints

- 不改变任何 HTTP 路径、方法、schema、状态码、错误码或 RouteOptions Interface。
- 不改变课程、课节、会话、Review、排期、画像、永久删除和 AI 生成规则。
- 不改变幂等键、资源版本、事件、Artifact、本地文件路径、时间来源或 ID 前缀。
- 保持当前 outbox/profile/evidence barrier 的串行与错误传播语义。
- 保持当前初始化、恢复、scheduler `start()` / `stop()` 和 degraded readiness 顺序。
- `local-application.ts` 最终不超过 160 行，`assemble.ts` 不超过 400 行。
- 不覆盖、回退或顺带提交开始本计划前已经存在的 weekly report、前端、合同或文档修改。
- 每次提交前运行 `git diff --cached --name-only`；若目标文件仍混有既有未提交 hunks，则延后该次提交，不使用 reset/checkout 丢弃它们。
