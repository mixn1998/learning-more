# Learning MORE 2.0：品牌视觉规范

## 1. 品牌定位

Learning MORE 的品牌标识服务于“可持续的个人学习闭环”，不把产品表达成通用聊天机器人、内容生成器或课程市场。标识需要同时传达三个稳定含义：

- 学习从一个真实理解点开始；
- 理解会向外建立连接并迁移到新的情境；
- 多次学习形成能够长期积累的认知复利。

## 2. 标识结构

产品采用“知识涟漪”图形作为主标识：

- 中心实心点表示当前形成的理解；
- 内外两层开放圆环表示理解逐层扩展，而不是封闭的知识边界；
- 连接内外层的斜向路径表示学习、迁移与行动之间的连续关系；
- 开放缺口使图形保持向外生长的方向，避免与地球、网络或通用 AI 星芒混同。

图形必须在 16–32 px 的浏览器图标尺寸下保持可辨，不依赖文字、渐变、阴影或细碎装饰完成识别。

## 3. 色彩与组合

主标识使用现有产品视觉系统中的三种颜色：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深墨色 | `#26313A` | 内层认知结构、中心点与主要文字 |
| 陶土色 | `#B96F43` | 外层扩展路径与品牌强调 |
| 暖白色 | `#FFFAF5` | 图标承载面与浅色界面背景 |

标准组合由图形标识和文字 `Learning MORE` 构成。产品副标题属于页面语境，不属于固定 Logo 文案；它在页头中与品牌文字组合，但可以随页面变化。

## 4. 产品使用范围

统一标识覆盖：

- 浏览器 favicon；
- 全局应用外壳页头；
- 正式课节导航、学习会话和只读课节记录等独立页头；
- 运行中心与计划流中的产品品牌区；
- 视觉测试夹具中的品牌页头。

课程模式徽标、学科标签、运行状态和页面状态不得替代产品 Logo。它们与品牌标识并列时继续表达各自的业务语义。

## 5. 实现约束

- 单一 SVG 资产作为浏览器图标和页面图形的事实来源，避免不同入口出现形状漂移。
- 页面通过共享品牌组件组合图形、产品名与可选副标题，不在业务页面重复手写品牌结构。
- 图形在页面中是装饰性内容；包含它的主页链接或品牌区域承担可访问名称，避免屏幕阅读器重复朗读。
- 品牌组件只负责品牌识别，不持有路由、运行状态或页面业务状态。
- 不生成独立位图作为主资产；需要导出平台位图时，应从主 SVG 确定性转换。

## 6. 验收标准

- 浏览器标签不再显示默认地球图标。
- 所有生产页头中的 `Learning MORE` 前均使用相同图形标识。
- 32 px 和 16 px 下仍能区分中心点、开放圆环和扩展路径。
- 标识颜色与现有暖白、陶土色、深墨色界面协调。
- 页面品牌副标题仍能按当前路由或工作区状态变化。
- 品牌结构具有组件测试，Web 类型检查与生产构建通过。
