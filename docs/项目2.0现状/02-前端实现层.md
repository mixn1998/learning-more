# Learning MORE 2.0：前端实现层

## 1. 技术与构建边界

前端位于 `apps/web`，当前技术栈为 React 19、React Router 7、TypeScript 5、Vite 8。共享 UI 位于 `packages/ui`，前后端传输合同和 Zod 解析器位于 `packages/contracts`。

前端只允许依赖：

- `apps/web` 自身代码；
- `@learning-more/contracts`；
- `@learning-more/ui`；
- React、React Router、React Markdown、Vite 等白名单框架依赖。

架构检查禁止前端直接导入服务端实现或 Node 平台模块。

## 2. 页面路由

应用使用 `BrowserRouter` 和 `useRoutes`。除首页外，主要页面按路由懒加载，并由统一的加载边界处理动态模块加载失败。

| 路由                                            | 当前页面                        | 主要实现                                                          |
| ----------------------------------------------- | ------------------------------- | ----------------------------------------------------------------- |
| `/`                                           | 主页                            | `features/home/home-page.tsx`                                   |
| `/courses/new`                                | 课程创建工作台                  | `features/course-authoring/authoring-page.tsx`                  |
| `/courses/:courseId`                          | 正式课程、大纲修改、课程 Review | `features/review/course-page.tsx` 与 `features/course/*`      |
| `/courses/:courseId/lessons/:lessonId`        | 课节导航或正式学习              | `features/learning/lesson-entry-page.tsx`、`session-page.tsx` |
| `/courses/:courseId/lessons/:lessonId/record` | 课节只读记录与 Review           | `features/history/lesson-record-view.tsx`                       |
| `/lessons/:lessonId`                          | 旧式课节兼容入口                | 重用正式课节路由                                                  |
| `/planning`                                   | 排期与计划流                    | `features/planning/planning-page.tsx`                           |
| `/history`                                    | 统计、日历、画像                | `features/history/history-page.tsx`                             |
| `/profile`                                    | 画像兼容入口                    | 重定向`/history?tab=portrait`                                   |
| `/runtime`                                    | 运行中心弹层                    | `features/runtime/runtime-center.tsx`                           |

所有页面位于统一 `AppShell` 内。运行中心以自定义 `Dialog` 打开，关闭时返回打开它的上一页，而不是固定跳转首页。

## 3. 应用外壳与运行身份

前端启动时读取 `/api/v1/runtime/ready`，将页面状态分为加载中、离线、已加载。已加载后继续比较：

- `protocolVersion`：不一致时禁止写入；
- `buildId`：不一致时禁止写入，受控重连确认目标构建后才重新开放；
- `instanceId`、`identityFingerprint`、Store/投影/Provider 状态：用于运行中心展示和恢复判断。

运行恢复由共享协调器串行执行四个阶段：核验实例、请求 Launcher 重连、等待健康、刷新运行身份和 AI 状态。探测失败发生在恢复过程中时不会立刻覆盖为最终离线状态。

## 4. 功能目录与页面职责

### 4.1 主页 `features/home`

主页消费单一 `/api/v1/home` 聚合视图，展示课程、草稿、课节和排期。它在客户端完成课程选择卡片投影：活动会话优先，其次使用服务端下一课推荐，再排除已放弃课节。推荐只展示原因、备选和 fallback 状态，不自动开始学习。

主页保存“学习方向 + 课程模式”作为一次路由状态交接，创建页直接消费该意图，避免在两个页面重复输入主题。

### 4.2 课程创建 `features/course-authoring`

创建页使用本地 reducer 管理模式、输入、会话、候选任务、流式 Markdown、确认和错误状态。服务端 `OutlineSessionView` 始终是权威状态，本地乐观状态只用于即时反馈。

主要组件包括：

- `CourseModeSelector`：九模式入口；
- `AssessmentPanel`：起点评估 Markdown；
- `CandidatePanel` / `OutlineWorkspaceView`：流式候选和结构化大纲；
- `ConfirmDialog`：显式确认正式课程；
- `DeleteDraftDialog`：草稿永久删除二次确认。

候选流通过 SSE 任务帧追加，不用前端自行拼接业务状态。页面刷新后读取会话中的活动任务 ID 并重连流。请求失败、候选合同拒绝、超时和连接中断分别映射用户文案。

### 4.3 正式课程 `features/course` 与 `features/review`

`course-page.tsx` 根据查询参数和课程状态组合三类视图：正式课程目录、大纲修改、课程 Review/已关闭归档。

大纲 Markdown 的页面投影集中在 `outline-markdown-projection.ts`：

- H1 作为课程标题；
- H1 后显式 50–100 字摘要作为课程摘要；
- 模块归属按真实 Markdown 层级和保存课节关系投影；
- 无法匹配的课节放入平铺区，不发明模块；
- 课节摘要使用正式课节目标；
- 新旧大纲差异由独立 diff 投影处理。

学科大类展示通过 `discipline-label.ts` 做确定性归一化。课程顶部、历史统计和规划筛选共用这一函数；当前规则只明确收敛商业/创业和数学/微积分，其他值原样返回。

### 4.4 学习 `features/learning`

`lesson-entry-page.tsx` 先加载课节预览和状态，再决定展示未开始导航、已放弃恢复、活动会话或已完成记录。

`session-page.tsx` 协调会话命令、AI 任务和服务端版本；`lesson-session-workspace.tsx` 负责正式学习布局；`message-stream.tsx` 负责结构化消息展示；`session-window-lifecycle.ts` 负责页面生命周期暂停/恢复。

当前实现要点：

- 开始会话后自动请求 AI 开场；
- 用户消息在请求返回前先显示；
- SSE 断线可按任务序号续读；
- 页面刷新可恢复服务端活动任务；
- AI 生成期间可见计时停止；
- 背景暂停不取消已启动任务；
- 服务端版本前进时先重新拉取权威状态，再重试用户动作；
- 第二标签页默认只读，可显式转移写入权；
- 已完成会话和最终 Review 从服务端只读水合。

### 4.5 规划 `features/planning`

规划页读取 `/api/v1/schedule` 和主页课程/课节上下文。客户端把服务端排期映射为周轨道和待安排列表，日期筛选初始为空。

单课节日期选择使用行内 `<input type="date">`。保存成功后直接使用响应中的排期项更新当前页面；失败时恢复原日期并显示行级错误。移动、调整时长、锁定、删除都遵循同样的权威响应回填方式。

`PlanFlowPanel` 只提交结构化约束并显示服务端确定性预览。策略或约束变化会让旧预览失效；确认前不修改正式排期。

### 4.6 历史与画像 `features/history`、`features/profile`

历史页按 URL 查询参数保持统计、日历、画像页签。日期切换会清空旧结果后重新加载，避免旧日期内容残留。课程和学科筛选从当前课程目录构建；课程目录不可用时仍保留事实统计工作区。

课节记录使用结构化角色，不解析消息文本前缀。原始会话、补充会话和 Review 通过页签分开，原始会话只读。

画像当前产品视图是 `portrait-workspace.tsx`。画像设置是本地 UI 设置；画像刷新命令仍调用真实后端，并用返回的完成版本替换当前显示。画像架构边界测试已经同步到当前文件名并通过。

### 4.7 运行中心 `features/runtime`

运行中心打开后每 5 秒轮询 Provider 状态和目录。AI 区支持：

- Mock、API、Codex CLI 选择；
- API Base URL、模型和密钥句柄；
- Codex 登录；
- 动态模型和推理强度选择；
- 应用 Provider、重连当前接口、检查接口。

服务区支持受控重连、前端构建同步和脱敏诊断。Launcher 控制写操作使用短期 capability，保存在 `sessionStorage`，403 且明确为 capability 失效时重新获取一次。

## 5. 客户端数据与命令模式

### 5.1 合同优先

所有 JSON 响应在进入页面前通过 `packages/contracts` 中的 Zod Schema 解析。HTTP 非 2xx 响应优先解析为统一 `ApplicationProblem`，页面依据 `code`、`retryable` 和关联 ID 决定恢复方式。

### 5.2 幂等与并发控制

写请求使用：

- `idempotency-key`：同一用户动作重试复用；
- `x-page-instance-id`：标识当前页面实例；
- `If-Match`：携带资源版本，拒绝过期写入；
- `x-csrf-token`：本地不安全方法的 CSRF 防护。

`useCommandAttempts` 按业务动作键缓存一次命令尝试，成功后清除；因此网络重试不会生成第二个业务命令。

### 5.3 状态管理

项目没有引入全局状态库。状态按责任分层：

- AppShell：运行身份、恢复协调和顶部状态；
- 路由参数/查询参数：页面选择和可分享视图状态；
- 页面 reducer/useState：短期交互和乐观反馈；
- 服务端资源版本：业务事实的最终来源；
- `sessionStorage`：仅保存短期 Launcher capability；
- 页面实例 ID：多窗口命令身份。

## 6. 共享 UI 与 AI 内容边界

`packages/ui` 当前导出按钮、卡片、字段、布局、状态条、对话框、页签、Toast、`AiContent` 和 `AiSurface`。

`AiContent` 是 AI Markdown 的统一渲染边界：

- GFM 表格；
- 行内和块级数学公式，KaTeX 渲染；
- 原始 HTML 清理；
- 宽表格横向滚动；
- Mermaid 代码块保留为明确 fallback，不在页面执行任意脚本；
- 对模型偶发的单行压缩表格和 LaTeX 分隔符做有限、可判定的标准化。

课程创建、教学、Review、周报和画像应复用该边界，不分别维护 Markdown 解析器。

## 7. 对话组件

共享对话组件位于 `apps/web/src/components/chat`：

- `UserMessageRow`：整行右对齐、消息状态、失败提示、时间和重试；
- `UserMessageBubble`：内容宽度、最大宽度、换行和失败色；
- `ChatComposer`：自适应高度 textarea、Enter 发送、Shift+Enter 换行、中文输入法组合态保护、错误和忙碌状态；
- `ConversationStream`：接近底部时自动跟随，用户向上阅读时保留位置并提供“回到最新消息”，通过无障碍区域播报 AI 开始/完成。

用户输入不再依赖普通 `div` 的默认排版，因此短文本不会纵向挤压，多行文本保留换行，气泡通过行容器在右侧对齐。

## 8. 视觉系统

全局视觉使用暖白纸面、陶土主色、低饱和状态色和模式主题变量。模式颜色只表达课程来源身份，不覆盖成功、警告、失败、只读等全局状态语义。

`docs/UI视觉预览` 是样例和审计资产，不是生产页面代码。生产构建检查会阻止样例脚本、样例目录引用或 demo 标记进入 `apps/web`。当前 React 页面另有 Playwright 视觉夹具，用于比对实际组件。
