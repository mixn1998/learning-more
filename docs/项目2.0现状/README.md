# Learning MORE 2.0 当前态文档

> 核验基线：`d201b8c`（2026-07-22）。本目录只描述已经进入当前代码、合同、测试或运行链路的能力；尚未实现的方向只会在“产品分析”中明确标为建议。

## 1. 当前结论

Learning MORE 2.0 已从架构设计阶段进入可持续迭代的本地优先产品阶段。它目前是一套面向单用户的 AI 学习系统：用户可创建课程、确认大纲、按课时学习、完成 Review、安排后续学习、查看历史统计，并从跨会话证据中获得学习画像。

当前系统的关键能力已形成闭环：

1. 课程创建和大纲修订保留版本历史，并把已完成课时作为不可改写的学习事实锚点。
2. 正式学习由阶段状态机约束，支持流式教学、追问、讨论、总结、关闭恢复和生成失败恢复。
3. 已完成课时的原始会话与 Review 保持只读；后续探索进入独立的补充学习会话。
4. 课程、会话、Review、规划和画像均落在本地文件数据目录，通过 Repository 接口隔离持久化实现。
5. 首页汇总使用源修订号、静态快照和 ETag；无数据变化时直接复用结果。
6. 画像由原始事实、会话聚合维度、候选证据和跨会话分析逐层形成，周六 00:00 异步刷新，也支持手动刷新。
7. Windows Task Scheduler 独立触发 Host；Host 守护 Launcher，Launcher 守护服务进程，并负责版本构建、验证、激活与回滚。

## 2. 已验证的系统边界

### 产品边界

- 单用户、本地优先、无登录、无云同步。
- 内容生成依赖可切换的 AI Provider；Provider、模型和推理强度属于运行配置，不是产品常量。
- 通用附件、网页抓取、多用户协作和云端同步尚未成为当前态能力。
- 旧数据通过显式迁移进入新结构，不在业务运行时长期保留多套兼容分支。

### 技术边界

- Monorepo：pnpm workspace。
- 前端：React、Vite、TypeScript。
- 后端：Node.js、TypeScript 模块化单体。
- 合同：共享 Zod schema、错误码、OpenAPI 和流协议。
- 持久化：本地 JSON/Markdown、事件、事实、读模型、事务日志和索引。
- 运行入口：`127.0.0.1:43119`；应用服务：`127.0.0.1:43120`。

## 3. 当前实现地图

后端包含 11 个领域模块：

- CourseAuthoring
- LearningSession
- InteractiveTeaching
- ReviewClosure
- Planning
- NextLesson
- LearningFacts
- GlobalUserProfile
- ProfileEvidence
- LearningPortrait
- GenerationRuntime

AI 运行时登记了 16 个场景，覆盖课程创建、大纲生成与对齐、教学、观察、补充学习、阶段/最终/课程 Review、周报、画像、下一课推荐、推理行为分析、语义学习档案和证据提炼。场景通过统一任务运行时获得幂等、租约、并发、重试、停止和 Provider 选择能力。
