## 核验口径

事实优先级如下：

1. 当前可访问的运行实例及其 HTTP 响应；
2. 当前分支的启动接线、路由、模块接口、领域模型和持久化实现；
3. 当前自动化测试、架构检查与静态检查；
4. 旧文档仅用于定位术语和线索，不作为事实来源。

文中使用四种状态：

- **已接入**：生产启动链已创建该能力，并有页面或 HTTP 路由可达。
- **已实现**：存在可执行实现和测试，但不一定进入当前产品主路径。
- **注册未接入**：存在类型、场景名或接口，但生产代码没有提交或调用路径。
- **测试夹具**：只在测试或视觉样例中出现，不能视为生产配置。
