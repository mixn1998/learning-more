# 画像证据与画像生成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** 建立从学习事实到候选证据、全局学习档案、复合证据包和版本化学习画像的完整可追溯管线。

**Architecture:** `ProfileEvidence` 消费事实并生成可撤回的 CandidateEvidence 和确定性 GlobalLearningProfile；`LearningPortrait` 读取冻结的 PortraitInputManifest，经 Evidence Packer 选材后调用 GenerationRuntime。画像是版本化解释，不是事实权威源。

**Tech Stack:** TypeScript 5.9.3、Zod 4.4.3、Vitest 4.1.9、fast-check 4.8.0、GenerationRuntime、React 19.2.7、Playwright 1.61.1。

## Global Constraints

- 先完成《实施计划-05》Phase Gate。
- 禁止把 UI telemetry、模型自述或单条弱证据直接写入画像事实。
- 每条画像结论至少引用满足规则的复合证据；无法满足时必须表达未知或低置信度。
- 画像版本、input manifest、evidence pack 和 provider/task reference 均不可变。
- Evidence Packer 必须确定性、预算可测、去重可解释。

**Interface:** Evidence 含 `evidenceId`、`claimDimension`、`sourceGroup`、`sourceRefs`、`dataKeys`、`observedAt`、`strength`、`polarity`、`extractorVersion`、`dedupKey`、`status active|superseded|retracted`。

~~~ts
export interface CandidateEvidence {
  evidenceId: string;
  claimDimension: string;
  sourceGroup: EvidenceSourceGroup;
  sourceRefs: readonly string[];

  polarity: 'supporting' | 'limiting' | 'contradicting';
  extractorVersion: string;
  dedupKey: string;
  status: 'active' | 'superseded' | 'retracted';
}
~~~

## Phase Gate

- 证据管线重放、批处理、崩溃恢复、撤回和版本升级均确定性。
- 全局学习档案只含可计算事实并明确分母、窗口和充分度。
- Evidence Packer 满足预算、去重、来源多样性、矛盾保留和复合证据规则。
- 每个画像 claim 可追溯到冻结 manifest 内的 active evidence；旧版本不可变。
- 画像 E2E、`pnpm verify` 与矩阵检查通过。
