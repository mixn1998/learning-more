# 备份、发布与全量验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** 完成 schema migration、store 校验、备份/恢复、损坏隔离、portable Windows 发布、供应链检查和 74 条功能等价全量验收。

**Architecture:** 所有危险维护操作都由离线 CLI 在独占 store lease 下执行；migration 与 restore 使用新目录构建、完整校验、原子指针切换和可回滚 journal。发布物包含固定 Node runtime、构建产物、Launcher、维护工具、schema/prompt assets 和 checksum manifest，但不包含用户数据或密钥。

**Tech Stack:** Node.js 24.17.0、pnpm 10.34.3、TypeScript 5.9.3、Vitest 4.1.9、Playwright 1.61.1、Windows 11 x64、CycloneDX SBOM。

## Global Constraints

- 先完成《实施计划-07》Phase Gate。
- MVP 不承诺旧原型数据的运行时兼容；只迁移本正式 Store schema 的受支持版本。
- 迁移、备份、restore 和 doctor 默认只读或新目录写入，不原位修补权威文件。
- 任何校验失败都必须保留原数据并提供机器可读报告。
- 发布候选必须在全新 Windows 用户、Unicode/空格路径和离线启动场景验证。
