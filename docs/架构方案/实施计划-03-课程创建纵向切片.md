# 课程创建纵向切片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** 完成“输入主题→澄清评估→生成多个候选大纲→修订→确认→创建正式课程”的首条业务纵向切片，并保存全部版本、材料来源和生成证据。

**Architecture:** `CourseAuthoring` 拥有 `OutlineSession` 状态机并协调 GenerationRuntime 与 Repository。候选和评估是可修订 artifact；确认命令在单一 UnitOfWork 内创建 Course、固定 OutlineVersion、LessonDefinition 集合和 outbox 事件。HTTP/React 只依赖共享合同。

**Tech Stack:** TypeScript 5.9.3、Zod 4.4.3、Fastify 5.10.0、React 19.2.7、React Router 7.18.0、Vitest 4.1.9、React Testing Library 16.3.2、Playwright 1.61.1。

## Global Constraints

- 先完成《实施计划-02》Phase Gate。
- 所有 AI 输出先作为不可信草稿解析；只有通过结构校验和用户确认才能进入正式课程。
- 候选版本不可原位覆盖；确认绑定精确 `outlineVersionId`。
- `courseMode` 只允许 `standard` 与八个已确认玩法值；四类玩法观察面不得进入运行时字段、课节类型、固定 Prompt 步骤或必交产物。
- 主题、目标、约束与材料原文属于用户输入事实，AI 推断不得伪装为事实。
- 每个命令测试覆盖重复提交、expectedVersion 冲突和进程重启恢复。
