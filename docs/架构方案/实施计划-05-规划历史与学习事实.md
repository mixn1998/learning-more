# 规划、历史与学习事实 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** 交付手工排期、计划流预览/确认、历史时间线、课程汇总、统计、日历和周读模型，并保证它们可从权威事件确定性重建。

**Architecture:** `Planning` 拥有 ScheduleItem 与 PlanFlow 的写模型；`LearningFacts` 只消费已提交领域事件，形成不可变事实和可丢弃读模型。查询不反向修改领域聚合，所有统计口径映射到已冻结 dataKey。

**Tech Stack:** TypeScript 5.9.3、Fastify 5.10.0、React 19.2.7、Vitest 4.1.9、fast-check 4.8.0、Playwright 1.61.1。

## Global Constraints

- 先完成《实施计划-04》Phase Gate。
- 事实时间与业务时间分离：`occurredAt`、学习区间、计划日期不得互相替代。
- 未确认计划流不能改变正式排期。
- 所有投影都必须证明增量执行与全量重建等价。
- 时区固定从 runtime config 注入，MVP 默认 `Asia/Shanghai`；存储时间为 UTC ISO 8601。
