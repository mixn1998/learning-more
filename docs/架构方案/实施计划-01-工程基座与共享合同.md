# 工程基座与共享合同 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** 建立可构建、可测试、可审计的 TypeScript Monorepo，冻结共享合同、依赖边界和 75 条功能等价断言的机器可读入口。

**Architecture:** pnpm workspace 承载 React Web、Fastify Server、Launcher 和共享包。`packages/contracts` 只包含可序列化类型与 Zod schema；领域实现不能反向依赖 app adapter。所有时间、ID 和 AI 输出通过测试端口注入。

**Tech Stack:** Node.js 24.17.0 LTS、pnpm 10.34.3、TypeScript 5.9.3、React 19.2.7、Vite 8.1.3、Fastify 5.10.0、Zod 4.4.3、Vitest 4.1.9、ESLint 9、Prettier 3。

## Global Constraints

- 项目根目录：`D:\workspace\Growth OS\Learning MORE`。
- MVP 仅支持单用户、本地优先、Windows 11 x64、`127.0.0.1`。
- 所有状态修改都要求 `commandId`；可重试 HTTP 命令要求 `Idempotency-Key`。
- 合同层不得导入 Node.js、Fastify、React 或文件系统 API。
- 新测试先失败，再写最小实现；每项任务单独提交。
- 不使用 `any`、非空断言或大面积 snapshot；必须显式处理 `CommandResult`、`ApplicationProblem` 与错误码。
