# 教学范例集说明与采样框架

> 本目录是教学内容研究样本，不是当前运行功能或固定 Prompt 合同。产品能力与教学状态边界以 [`../项目2.0现状/01-功能设计层.md`](../项目2.0现状/01-功能设计层.md) 为准。

## 1. 范例集研究目标

本范例集主要研究三件事：

1. **课程如何组织**：内容怎样从入口推进到中心理解，为什么学习者愿意继续走下去。
2. **教师如何讲述**：抽象知识怎样变成自然、清楚、具体、有节奏的解释。
3. **学习如何互动**：什么时候让学习者先猜、先选、先解释，回答后又怎样改变下一步教学。

事实准确、学科方法和适用边界是所有范例的准入底线，但不是范例集唯一目标。范例不能只证明“内容没有错”，还要回答：它为什么抓人，为什么读得进去，为什么愿意继续想。

## 2. 什么叫“抓人”

抓人不是使用夸张标题、悬念套话或娱乐化包装，而是让学习者尽快遇到一个值得解决的认知张力。

有效入口通常来自以下一种或几种力量：

- **熟悉事物突然变得不确定**：明明每天都说“还是原来那个”，却解释不清判断依据。
- **直觉与结果冲突**：每换一块木板都像是原船，全部换完后却开始犹豫。
- **具体问题牵出更大结构**：解方程为何最终会走向空间与变换。
- **现实后果迫使判断**：不同答案会改变责任、决策、解释或行动。
- **可验证的惊讶**：先让学习者预测，再用例子、数据、推导或反例检验。

好的入口会产生真实的“我想知道为什么”，而不是告诉用户“本节非常重要”。

## 3. 课程组织的核心节奏

推荐把课程组织成连续的认知事件，而不是并列知识点清单：

```text
具体触发
→ 学习者作出初步判断
→ 新事实或反例制造缺口
→ 引入恰好够用的概念
→ 用概念解释刚才的冲突
→ 让学习者再次判断
→ 暴露更深一层问题
→ 形成阶段性收获
```

每一步都应同时满足两点：

- 回答上一刻真实出现的问题。
- 让下一步成为认知上的自然需要。

如果一个段落只是因为模板规定“这里该讲定义、例子或边界”而出现，它就不属于主线。

## 4. 保持阅读兴趣的九种教学动作

这些动作是候选策略，不是每节课都要填满的固定模板。

### 4.1 先判断，再揭示

先让学习者预测、选择或表达直觉，再给出解释。已经作出判断的人，更容易注意结果与自己预期的差异。

### 4.2 从对象进入，再命名概念

先让人看见方程、船、案例、文本句子、实验现象或代码行为，再给术语。术语负责压缩已经理解的经验，不能代替经验本身。

### 4.3 用最小变化制造张力

一次只改变一个条件，观察判断是否随之改变。渐进替换、边界案例和控制变量都可以产生这种效果。

### 4.4 让反例承担剧情作用

反例不是补充材料，而是让已有解释遇到真正困难。它应明确击中哪条判断，并迫使学习者修正什么。

### 4.5 在关键处切换表示

同一对象可以从图形、公式、语言、表格、时间线、案例或流程观察。切换表示应解决当前理解障碍，不用于展示形式丰富。

### 4.6 及时给出小回报

每一屏或每个信息单元都应留下一个可说出的新理解，例如：

- 原来“很像”和“就是同一个”不是一回事。
- 原来矩阵是表示，变换才是它描述的对象。
- 原来同一个结果可能由不同机制产生。

学习者持续获得小回报，才愿意走向更复杂的解释。

### 4.7 用选择的代价代替标准答案

在哲学、决策、法律和复杂社会问题中，趣味常来自“每个答案都会牺牲什么”。比较立场的解释力和代价，比过早宣布唯一答案更有张力。

### 4.8 把知识连回用户经验

迁移问题应使用用户能够想象或实际遇到的对象，但不能只做表面换词。必须保留原问题的关系结构和判断难点。

### 4.9 在仍有余味时收束

阶段结尾应给出真实收获，同时保留一个由当前结论自然产生的新问题。不能使用“下一节更精彩”之类空悬念。

## 5. 教学讲述方式

### 5.1 自然教师口吻

- 像面对一个正在思考的人，而不是向评审汇报课程设计。
- 可以承认学习者回答中的合理部分，再精确指出需要升级的位置。
- 少用“你必须、学习者应、本段将、认知推进”等命令或编排语言。
- 不连续堆叠定义；定义出现后立即回到对象、例子或判断。

### 5.2 句子与段落节奏

- 关键问题和关键判断可以短。
- 复杂解释拆成数句，每个自然段只承担一个主要动作。
- 长段落之间使用问题、对比、表格、公式、图示或例子改变阅读节奏。
- 标题不复述正文；正文第一句应立即增加新信息。

### 5.3 生动性的来源

生动性来自：

- 可想象的对象与动作。
- 条件变化造成的结果差异。
- 具体细节、真实案例、数据、公式或文本证据。
- 学习者直觉被验证、修正或反转的过程。

生动性不来自：

- 夸张形容词。
- 营销式标题。
- 与学科无关的强行故事。
- 为了热闹而加入不能推动理解的互动。

## 6. 互动设计准则

一次有效互动至少承担一种功能：

- 读取已有理解。
- 让学习者作出预测。
- 暴露概念混淆。
- 要求选择判断标准。
- 构造反例或边界。
- 把当前方法迁移到新对象。

用户回答后，系统不能只说“回答得很好”。后续回应应完成：

```text
识别回答中成立的部分
→ 找到最值得处理的一个缺口
→ 选择解释、对比、反例或追问
→ 给出新的可见内容
→ 让下一次回答有明确对象
```

这套过程属于动态教学编排层，不是新的正式思维模式。

## 7. 每份范例的统一采样维度

这里的“统一”只指观察问题统一，不指范例文档结构统一，更不指未来课程必须复用同一套章节、模块或卡片顺序。每份案例的章节只是把当次课程设计流展开后的记录方式；真正需要学习的是：设计者如何根据主题、学习者、证据和目标，选择下一步教学动作。

范例集应以元方法论的视角使用：比较不同范例如何形成入口、制造张力、安排证据、改变学习者任务、处理边界并完成迁移，而不是统计每个范例都出现了哪些模块。后续案例可以增加、合并或跳过下列观察维度，只要能说明课程设计流为什么这样展开。

| 维度 | 要回答的问题 |
| --- | --- |
| 开场抓手 | 第一处让人想继续读的张力是什么 |
| 中心主线 | 内容如何围绕一个核心困惑连续推进 |
| 问题递进 | 下一问是否由上一问的答案或缺口自然产生 |
| 具体载体 | 使用了什么对象、案例、公式、文本或现象 |
| 解释动作 | 定义、对比、推导、机制、反例如何按需出现 |
| 小回报 | 每个阶段让学习者新懂了什么 |
| 互动节点 | 为什么要在这里让用户回答 |
| 回答适配 | 不同回答会怎样改变下一步讲解 |
| 视觉节奏 | 哪些内容适合段落、表格、图示、公式或对照 |
| 学科特异性 | 哪些组织方式只适合当前学科 |
| 事实边界 | 哪些直观表达需要限定语境 |
| 模板化风险 | 哪些好形式不能被机械复制 |

## 8. 当前范例提供的九种不同吸引力

### 数学：从具体问题走向更大的结构

线性代数范例的吸引力来自“原来解方程背后还有空间和变换”，以及同一个向量在几何、坐标和公理视角之间切换产生的理解升级。

### 哲学：让熟悉直觉在反例中失去稳定

忒修斯之船范例的吸引力来自渐进替换和标准冲突。学习者每接受一步，就更难解释最终为何犹豫；每选一个标准，又会遇到专门击中它的反例。

### 哲学系统课程：让理论从前一方案的缺口中自然出现

语境主义知识论范例的吸引力来自理论发生史。它先让日常知识、怀疑论和知识封闭性形成张力，再比较不同方案各自保留什么、牺牲什么。JTB、Gettier问题、相关选择理论和语境主义不是并列知识点，而是沿着尚未解决的问题依次出现。

这类深入课程需要同时保持两层主线：课程导入负责建立理论坐标、争论版图和学习路线；课节正文负责沿一条论证缺口深入。两层不能被同一套卡片模板压平。

### 计算机：让结构选择变成可重复使用的决策框架

数据结构范例的吸引力来自操作需求与组织方式之间的反复取舍。图书管理员、电话本和超级计算机不是装饰性故事，而是分别承载“为什么需要结构”“为什么需要复杂度语言”和“实际速度与增长率如何区分”三个理解动作。

它还展示了技术学科的一个重要特征：用户回答即使方向正确，也可能缺少定义边界、因果解释或适用条件。后续讲解应继续施加一个具体压力，把“重复结论”推进到“能够用该概念解释新情境”。

后续范例应继续寻找各学科自身的吸引力来源，而不是统一复制“先讲故事再提问”。

### 经济学：让熟悉标签在边界与动态机制中失效

宏观经济循环范例的吸引力来自一个逐层加压的过程：学习者先能判断“漏出”或“注入”，再被追问资金相对于哪个系统边界流动；先能接受 `S = I`，再被要求解释计划背离如何通过非意愿库存、收入和产出调整得到结果。

它展示了另一种综合课组织方式：不靠陌生故事或反常识结论抓住注意力，而是让一个看似已经掌握的标签在跨国、跨期和多部门情境中逐渐失去充分性。学习者每次回答正确，教师都保留正确部分，同时只增加一个必须解释的维度：流向、边界、时间、后续流量或机制。

这类范例的核心吸引力不是“经济循环”这个主题本身，而是：

- 从静态分类推进到资金流向追踪。
- 从自然化的系统名称推进到明确声明建模边界。
- 从事后恒等式推进到事前计划和动态调整。
- 从课堂答案推进到对学习者思维模式的 Review。

它还补充了一类重要的复盘证据：学习者可能已经能够快速接受框架、在某些复杂问题上做出高精度区分，但仍会在其他情境中停留于正确标签。复盘不能把这种表现压缩为“掌握/未掌握”，而应指出已经成立的推理、最值得推进的一个缺口，以及下一次可执行的分析动作。

### 游戏设计：让反馈成为行为塑造与决策循环的转折点

游戏设计范例的吸引力来自把一个容易被当成表现层的对象重新放回系统：反馈不是游戏完成后的音效和动画，而是玩家输入、游戏响应、玩家理解和下一次决策之间的连接机制。

第一课先从行为塑造进入，再给出“可感知响应—因果关系—下一次决策”的定义，随后用游戏循环、反馈误区、正负反馈和《黑暗之魂》案例逐层推进。它展示了另一种课程组织方式：先回答一个设计对象为什么存在，再拆解它由什么构成、如何表达、何时出现、如何失效，最后进入综合设计。

这类范例的吸引力不是反馈形式很多，而是让学习者发现：

- 反馈是否存在，决定玩家能否继续理解和决策。
- 反馈强度不能脱离风险回收、学习机会和下一次尝试单独判断。
- 反馈数量不等于反馈质量，噪音可能掩盖有效信息。
- 练习可以从“识别反馈”推进到“诊断反馈缺失造成的决策问题”。

该范例还补充了“证据不足时不生成 Review 结论”的采样边界：当前材料包含课程地图、第一课正文和练习，但没有用户实际作答，因此可以分析互动停靠点和 Review 入口，不能虚构学习者的强项、薄弱点或掌握程度。

### 论证交锋：让对立立场成为课程大纲的推进动力

远程办公范例的主要价值不在于它提供了一个待裁决的答案，而在于它展示了争议型主题如何被组织成一条课程大纲：先建立问题为什么难，再分别钢人化正反方，随后用情境变量拆分二元问题，补充长期、权力和价值维度，最后进入研究阅读和决策迁移。

它提供了一种不同于“按知识点讲完再总结”的课程组织方式：每个模块都回应前一模块留下的认识缺口。测量困境要求方法论检查；正反方论证要求情境框架；情境框架仍遗漏权力和长期价值，于是需要第三维度；完成争论理解后，才进入不同角色的实践决策。

可迁移的不是远程办公的立场，而是以下玩法结构：

- 对立立场都必须获得完整、最强的论证空间。
- 对称呈现不等于证据权重完全相同。
- 利益相关方地图用于提示审计，不直接替代事实判断。
- 最终出口不是宣布哪一方获胜，而是把争论改写成情境化决策。

当前材料没有真实交锋记录，因此本范例可以作为“论证交锋课程大纲”采样，不能作为用户辩论表现或 Review 生成的样本。

### 历史场景案例：让历史解释在任务和证据的推进中形成

法国大革命范例的主要价值不在于提供一份革命史结论，而在于展示场景案例如何承担课程大纲的组织功能：先让学习者进入财政顾问的现场，再让数据制造矛盾；随后让改革方案在多方利益和制度否决点中卡住，再追踪财政问题如何通过制度、政治语言、信息传播和象征事件转化为革命；最后用比较案例、因果图和反事实检验解释边界。

它展示了历史综合课的一种任务递进：

```text
诊断
→ 决策
→ 解释卡壳
→ 追踪转化
→ 压力测试
→ 反事实判断
```

可迁移的不是法国大革命的四单元标题，而是让每个单元承担不同的历史分析动作：读史料、重建当时约束、分析利益与制度、区分事件和象征、比较不同结果，并标出因果链中的证据缺口。场景不是故事包装，而是控制信息顺序和决策条件的教学结构。

当前材料是课程大纲，没有用户实际完成场景任务的答案，因此可以采样场景任务链、史料角色和理论出现顺序，不能生成历史分析能力的 Review 结论。

### 商业与管理行业分析：让知识地图从节点关系中产生竞争判断

香水行业范例的主要价值不是提供一个行业百科，而是示范如何分析一个行业：先重新定义行业的真实价值来源，再建立上游、制造、产品、品牌、渠道、监管、竞争和消费者的节点网络；随后判断不同企业的节点控制权、强弱分布、飞轮和风险击穿点，最后把地图转化为咨询行动问题。

它展示了商业分析课程的一种元方法：行业地图不是固定分类表，品牌对照不是总分排名，行动框架也不是另加的清单。节点、关系、企业画像和咨询问题应沿着同一条分析流逐步产生。换到其他行业，应重新发现决定价值、权力、利润和风险传导的节点。

当前材料没有用户实际完成新行业拆解或品牌对照的答案，因此可以采样行业地图、节点关系和行动框架的形成方式，不能生成行业分析能力的 Review 结论。
