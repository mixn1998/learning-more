# 哲学教学范例：语境主义知识论系统课程

## 1. 范例信息

- 学科领域：哲学
- 主题：知识论语境主义
- 学习水平：深入理解
- 课程类型：标准课程
- 范例范围：课程导入 + 第一节正文
- 课程级组织方式：理论定位、核心悖论、理论谱系、对立观点、反驳路线
- 课节级组织方式：前驱理论解决什么、付出什么代价、为何需要下一种理论
- 核心能力：概念分析、论证重构、理论比较、反例识别、层次区分
- 来源：用户提供的代表性教学范例
- 当前定位：哲学系统课程的教学组织与讲述范例；经过初步事实校准，不作为所有哲学主题的固定模板

> 范围说明：本文件不是一节课的完整文字预算。前半部分是课程导入，负责建立全局认知地图；后半部分是第一节正文，负责解释语境主义从什么问题中产生。两者在产品中应作为独立生成阶段和独立阅读单元。

## 2. 这份范例为什么重要

这份范例展示了一种不同于“问题链微课”的哲学教学形态。

它面对的不是一个可以在单节课中完成的小悖论，而是一组具有历史脉络、内部版本和竞争理论的系统性知识。因此，它没有从一个孤立定义开始，而是先回答：

1. 语境主义在知识论中处于什么位置？
2. 它试图处理哪组无法同时保留的直觉？
3. 它相对于怀疑论、不变论和相关选择理论做了什么移动？
4. 学习者最终需要具备怎样的理论区分能力？

范例的吸引力来自“理论为什么非出现不可”。学习者不是被告知一张人物和观点清单，而是先看见旧理论留下的缺口，再沿着缺口走到语境主义。

## 3. 双层主线

### 3.1 课程导入主线

```text
知识论的三层问题
→ 语境主义的特殊位置
→ 日常知识、怀疑论与封闭性之间的张力
→ 经典应对方案及其代价
→ 语境主义的核心语义移动
→ 需要回答的三个机制问题
→ 版本、对手、反驳与延伸的学习地图
```

导入的任务不是提前讲完各家理论，而是让学习者知道整个课程围绕什么冲突展开、不同章节为什么依次出现，以及学完后应当能够作出哪些精确区分。

### 3.2 第一节主线

```text
JTB为什么曾经合理
→ Gettier如何暴露偶然性缺口
→ 相关选择理论如何重新描述知识
→ “相关”由谁决定成为新问题
→ 归因语境进入理论视野
→ 银行案例固定语境主义的基本直觉
```

第一节的中心问题不是“语境主义的定义是什么”，而是：

> 为什么知识论会需要一种让知识归因标准随语境变化的理论？

## 4. 值得保留的教学机制

1. **先定位再深入**：在给出定义前，先说明理论在学科问题地图中的位置。
2. **用不可兼得的命题制造张力**：学习动力来自三种直觉无法同时保留，而不是来自“本理论很重要”的宣告。
3. **把理论比较写成选择与代价**：每种理论都说明保留什么、放弃什么、为什么仍有人接受。
4. **先建立直觉，再压实精确性**：使用“高”“平”等类比建立入口，但随即指出类比的边界。
5. **由旧理论的失败引出新理论**：新术语只在它能够解决当前缺口时出现。
6. **区分不同论点层次**：认识状态是否变化、知识归因句的真值条件是否变化、评价语境是否变化，不能混为一谈。
7. **检测要求理论辨析**：不只复述定义，而要识别误解、重构论证和比较相邻理论。
8. **明确学习承诺**：课程提前告诉学习者，哪些地方会停下来复述、构造反例或区分概念，但不把这些教学动作机械铺满每一节。

## 5. 哲学事实校准与争议边界

### 5.1 语境主义的理论层次

归因者语境主义通常主张，知识归因句“S知道P”的真值条件会随归因者的会话语境变化。不同版本对这种变化的语义机制、标准结构和触发条件有不同解释。入门课程可以说“知识标准随归因语境变化”，但不宜未经论证便断言所有语境主义者都把“知道”分析为普通指示词，或都认为它在不同语境中指称完全不同的关系。

### 5.2 三命题张力的严格表述

日常知识、怀疑论前提和知识封闭性可以形成经典反怀疑论张力，但严格论证需要明确封闭性原则的版本、主体是否知道蕴含关系，以及是否完成适当推理。课程中的简化形式用于展示问题结构，后续应再处理闭合、已知闭合和能力条件之间的区别。

### 5.3 相关选择理论与斑马案例

Dretske著名的动物园案例通常被称为“斑马案例”。它用于讨论知识、相关替代可能性和封闭性，不应称为谷仓案例的直接前身。谷仓立面案例属于另一组知识论案例，涉及环境运气、可靠性和安全性等问题。

### 5.4 银行案例的论证力

DeRose的银行案例是语境主义的重要直觉材料，但风险变化究竟改变归因语境、主体的认识地位，还是知识与实践理性的关系，本身正是语境主义、主体敏感不变论和实用侵入理论争论的内容。课程应把语境主义解释呈现为一种有竞争力的诊断，而不是把案例直接当作已经证明语境主义。

### 5.5 JTB的历史定位

“有辩护的真信念”是知识分析的经典框架。Gettier案例说明JTB条件并不充分，但这并不意味着此后所有理论都采用简单的“JTB加第四条件”形式。课程可以用这一图景建立历史入口，同时提醒学习者后续方案包含因果论、可靠主义、安全性、德性知识论等不同重构方向。

## 6. 校准后的课程导入范例

### 6.1 语境主义在研究什么

在进入任何细节之前，先看整体坐标。

知识论的核心问题大致可以分成三层：

1. **分析问题**：知识是什么？什么条件共同构成知识？
2. **范围问题**：我们实际上知道什么？知识的边界在哪里？
3. **来源问题**：知识如何获得？感知、理性、记忆和证词各有什么地位？

语境主义横跨前两层，却提出了一个更靠后的问题：

> 当我们说“某人知道某事”时，“知道”的判断标准是否在所有语境中保持不变？

它不是先问张三究竟有没有知识，而是先检查我们作出知识归因时使用的语言和标准。

这就是语境主义的重要移动：它没有直接增加一条新的知识条件，而是重新检查“我们知道什么”这类问题是怎样被问出来的。

### 6.2 问题从哪里开始

考虑三种都很有吸引力的判断：

**第一种判断：日常生活中，我们确实知道很多事情。**

“我知道我有手。”

“我知道今天是星期三。”

“我知道北京在中国。”

**第二种判断：我们似乎无法排除某些极端欺骗情形。**

例如，我可能设想自己只是一个被输入模拟信号的缸中之脑。日常经验似乎不能独立排除这种可能性。

**第三种判断：知识似乎可以沿着已知的逻辑蕴含传导。**

如果我知道P，也知道P蕴含Q，并完成了相应推理，那么我似乎也应当知道Q。

现在把三者放在一起：

```text
我知道我有手
我知道“如果我有手，那么我不是无手的缸中之脑”
按照封闭性，我应当知道自己不是这种缸中之脑
但怀疑论者说，我无法知道自己不是缸中之脑
```

真正困难的地方在于：每一步单独看都很有说服力，但它们不能毫无条件地同时保留。

### 6.3 理论家可以怎样选择

| 路线 | 主要移动 | 保住什么 | 付出什么代价 |
| --- | --- | --- | --- |
| 强怀疑论 | 大幅收缩日常知识 | 怀疑论前提与封闭性 | 与日常知识直觉冲突 |
| 否定或限制封闭性 | 阻止知识沿某些蕴含传导 | 大量日常知识 | 需要解释强烈的封闭性直觉 |
| 不变论回应 | 维持统一知识标准，并削弱怀疑论前提 | 日常知识与统一语义 | 需要解释高标准语境中的知识否认 |
| 语境主义 | 让知识归因标准随归因语境变化 | 两类知识直觉 | 需要提出可信的语义机制 |

语境主义试图说：看似相互冲突的知识归因，可能出现在不同的语境标准之下。它提供的是一种语义诊断，但这个诊断能否成立，必须由后续理论来证明。

### 6.4 核心论题

可以先用一句较精确的话固定方向：

> 知识归因句“S知道P”的真值，不仅与S的证据、信念和认识状况有关，也可能与作出该归因的人所处的会话语境有关。

因此，即使主体、命题和证据状态相同，在不同归因语境中，“S知道P”仍可能得到不同判断。

以“张三知道车停在楼下”为例。普通闲谈中，张三清楚记得自己刚刚停车，可能已经足够。可如果车辆是否在场关系到一项高风险决策，对话者可能要求排除更多错误可能。

语境主义关心的不只是人变得谨慎，而是知识归因句的成立标准是否随对话环境发生变化。

### 6.5 用类比建立直觉，同时保留边界

“高”会随比较对象变化。

一个人在普通成年人中很高，放进职业篮球运动员中却未必高。两次判断使用的标准不同。

“平”也会随用途变化。

一块地对日常行走足够平，对精密光学实验却远远不够平。

语境主义者希望说明，“知道”也具有某种标准敏感性。不过，这只是入口类比。究竟是比较标准变化、相关可能性变化，还是语义内容发生其他变化，需要由具体版本说明。

### 6.6 第一个必须压实的区分

语境主义不等于认识论相对主义。

| 比较项 | 归因者语境主义 | 知识相对主义的一般方向 |
| --- | --- | --- |
| 关键语境 | 作出知识归因时的语境 | 后来评价该断言时的语境 |
| 真值变化发生在哪里 | 断言产生时的真值条件 | 断言在不同评价情境中的真值 |
| 理论任务 | 解释知识归因为何对说话语境敏感 | 解释无过失分歧与评价变化 |

这里先留下一个问题：

> 语境主义究竟是在保住“我知道我有手”，还是只说明这句话在某些语境中为真？

两种说法听起来很接近，理论后果却不相同。

### 6.7 所有版本都要回答的三个问题

**问题一：语境中什么因素会改变知识标准？**

是现实风险、对话目的、被显著提起的错误可能性，还是隐含的对照范围？

**问题二：标准怎样变化？**

只要有人提出怀疑，标准就会无限升高吗？不同可能性是否遵循明确的进入和忽略规则？

**问题三：理论怎样保住日常知识？**

如果哲学讨论可以让大量日常知识归因变假，普通语境中的知识为什么不只是“宽松地说说”？

后续每一种语境主义理论，实际上都在填写这三个槽位。

### 6.8 整体学习路线

```text
第一层：问题背景
├── JTB与Gettier问题
├── 怀疑论张力与知识封闭性
└── 相关选择理论

第二层：语境主义的主要版本
├── Lewis：可能性消去与语境规则
├── DeRose：标准强度与知识归因
└── Cohen：相关替代与归因语境

第三层：通过对手深化理解
├── 主体敏感不变论与实用侵入
├── 温和不变论
└── 知识相对主义

第四层：核心反驳
├── 语言证据是否足够
├── 实践推理与行动依据
├── 奇异合取与语义直觉
└── 语境机制能否被精确说明

第五层：进一步问题
├── 知识归因与证词
├── 语境、风险与认识规范
└── 语境主义是否真正回答怀疑论
```

学完后，不能只说“不同场合对知识要求不同”。至少应当能够回答：

1. 归因者语境与受试者处境有什么区别？
2. 标准升高的机制是什么，而不只是“大家变谨慎了”？
3. 语境主义与相邻的不变论、实用侵入和相对主义怎样区分？

## 7. 校准后的第一节正文范例

# 第一节：语境主义为什么会出现

## 7.1 为什么要从前史开始

语境主义不是凭空发明的解决方案。

它回应的是此前知识分析和反怀疑论理论留下的一连串缺口。如果不知道旧理论为什么失败，就很难判断语境主义究竟解决了什么，也无法判断它是不是把认识论问题改写成了语言问题。

## 7.2 JTB为什么一度令人信服

经典的知识三元分析通常写作：

```text
S知道P，当且仅当：
S相信P
P为真
S有理由相信P
```

每个条件都在排除一种明显不够格的情况。

- **真**排除错误信念。一个假命题不能成为被知道的事实。
- **信念**排除偶然说中但本人并不接受的猜测。
- **辩护**排除毫无根据却幸运猜中的真信念。

JTB最有吸引力的直觉是：知识应当是受到认识根据支持的真信念，而不是运气。

## 7.3 Gettier击中了哪里

Gettier案例表明，即使真、信念和辩护都具备，真值与辩护之间仍可能只是偶然相遇。

考虑Smith和Jones的案例：

1. Smith得到强力证据，相信Jones会得到工作。
2. Smith看见Jones口袋里有十枚硬币。
3. Smith据此相信：“得到工作的人口袋里有十枚硬币。”
4. 最终得到工作的是Smith自己。
5. Smith不知道，自己的口袋里也恰好有十枚硬币。

Smith相信的结论为真，也似乎有理由相信它。但结论之所以为真，与他的证据支持方式发生了错位。

问题不只是推理里出现了一个假命题，而是：

> Smith得到真信念的方式仍然受到认识运气支配。

这迫使知识论寻找更强的连接：因果联系、可靠过程、反事实追踪、安全性，或者其他能够排除偶然性的条件。

### 互动停靠点一

试着构造一个案例：某人没有显式依赖一个假前提，却仍然因为运气而得到有理由的真信念。

这里不是考记忆。你的案例会帮助判断，你把Gettier问题理解成了“不能经过假命题”，还是理解成了“辩护与真之间不能偶然错接”。

## 7.4 相关选择理论改变了问题

相关选择理论提供了另一种入口：

> S知道P，需要能够排除P的所有相关替代可能性，而不是排除每一个逻辑上可描述的可能性。

如果你在动物园看见一只斑马，可能需要排除它是一头普通骡子，或者在有特殊理由时排除它是一头被涂装的骡子。但通常不需要先排除自己是缸中之脑，才有资格说“我知道那是斑马”。

这个理论很好地捕捉了日常知识判断：知识要求不是全知全能，而是对当前真正相关的错误可能性负责。

可它马上留下了更棘手的问题：

> 什么使一个替代可能性成为“相关”的？

如果相关性完全由客观环境决定，哲学讨论为什么会让缸中之脑突然变得难以忽略？

如果只要有人把一种可能性说出口，它就自动变得相关，知识标准又会不会被任意抬高？

相关选择理论在这里出现分叉：

```text
相关性主要由客观情境决定
→ 走向不同形式的不变论

相关性受到知识归因语境影响
→ 开始走向语境主义
```

语境主义正是从“相关性由谁决定”这个缺口中进入。

## 7.5 银行案例怎样固定直觉

DeRose用两组平行案例展示了标准变化的吸引力。

**低风险情境**

周五下午，夫妻二人路过银行。队伍很长，其中一人记得两周前银行周六营业，于是说：“我知道银行明天开门，我们周六再来。”

在没有紧迫后果时，这个知识归因听起来很自然。

**高风险情境**

证据保持不变，但支票必须在周一前兑现，否则会产生严重后果。对方问：“你确定营业时间没有改吗？”此时说“我不知道银行明天是否开门”，听起来同样自然。

语境主义者希望这样解释差异：主体的记忆证据没有改变，但归因语境要求排除的错误可能性增加了，因此知识归因的标准升高。

不过，案例还没有自动证明语境主义。竞争理论会追问：风险是否真的只改变了说话语境？它有没有改变主体应当怎样形成信念和行动？

### 互动停靠点二

在银行案例中，最值得区分的是：

- 主体相信的内容是否改变；
- 主体拥有的证据是否改变；
- 行动风险是否改变；
- “知道”的归因标准是否改变。

先选出你认为语境主义最需要依赖的一项，再说明其他变化为什么不足以单独解释两次判断。

## 7.6 本节阶段收束

现在可以看见语境主义出现的连续理由：

```text
JTB没有排除认识运气
→ 知识理论开始寻找更可靠的真值联系
→ 相关选择理论要求排除相关错误可能性
→ “什么算相关”缺少稳定解释
→ 归因语境成为可能的决定因素
→ 语境主义试图同时解释日常知识与高标准知识否认
```

第一节真正留下的不是一句定义，而是一个待检验的理论承诺：

> 如果知识归因标准随语境变化，我们是否真的能够保住日常知识，同时又认真对待怀疑论压力？

下一步应进入Lewis、DeRose或Cohen的具体机制，检查它们怎样决定哪些可能性可以被忽略、哪些不能。

## 8. 第一节理解检验

### 检验一：定义精度

用一句话表述归因者语境主义的核心论题。必须明确是谁的语境影响什么，不能只写“不同场合要求不同”。

### 检验二：层次识别

有人说：“高风险时，人会变得没那么自信，所以银行案例没什么特别。”

请解释这句话为什么还没有触及语境主义的核心主张。

### 检验三：理论发生史

相关选择理论与语境主义都谈相关可能性。它们之间最关键的分叉是什么？

### 检验四：案例辨析

银行案例中，语境主义解释主要依赖哪项变化？

1. 主体相信的命题内容
2. 主体拥有的证据
3. 知识归因句在语境中的成立标准
4. 银行实际上是否营业

选择一项，并说明为什么不能仅凭这个案例彻底排除其他理论。

## 9. 互动生成建议

本范例不应一次性把全部正文推给用户。更合适的动态教学节奏是：

```text
课程导入：建立理论坐标和核心张力
→ 用户选择最难理解或最想追问的冲突
→ 第一节前半：JTB与Gettier
→ 用户构造或判断一个Gettier案例
→ 根据回答选择补充反例或继续进入相关选择理论
→ 用户判断“相关性”由什么决定
→ 银行案例与竞争解释
→ 本节检验与下一节路线
```

用户回答后，系统应先识别其论证中成立的部分，再选择一个最关键的缺口继续。不能无论用户如何回答，都返回预先写好的下一张卡片。

## 10. 对课程生成架构的启示

1. 课程导入和课节正文需要不同的主线编译器输出，不能共用一套卡片骨架。
2. 深入理解课程需要保留理论谱系和论证依赖，时长只改变每个节点的展开深度，不能任意删除关键发生关系。
3. 表格、树状图和检测题是按需选择的表达工具，不是每节课必须填写的模块。
4. 主线编译器只固定核心张力、认知变化和必要论证链；具体类比、反例、互动位置由教学生成阶段动态决定。
5. 哲学课程的完成标准不是覆盖了多少术语，而是学习者能否重构论证、区分相邻理论并说明每种选择的代价。
6. 该范例中的“理论谱系式系统教学”是正式思维模式与教学模块结合后的衍生教学形态，不应提升为新的正式思维模式。

这份范例的学习重点不是记住“JTB → Gettier → 相关选择理论 → 语境主义”的固定路线，而是观察理论如何从前一方案无法处理的缺口中出现。课程导入先建立理论地图和总张力，第一节再沿一个具体论证缺口深入，两层主线由不同任务共同构成。

可迁移的元方法是：先判断当前课程需要建立什么整体坐标，再选择一条不可合并的论证缺口作为课节推进轴；每引入一个理论，都要说明它解决了什么、保留了什么、又把什么问题推迟给下一步。理论谱系和银行案例只是本主题的载体，不是通用章节模板。
