# 经济学教学范例：宏观经济循环——从“钱在转”到理解整个系统

## 1. 范例信息

- 学科领域：经济学
- 主题：宏观经济循环、漏出与注入、系统边界、事后恒等式与事前计划
- 学习水平：基础巩固
- 课程类型：综合课
- 范例范围：课程导入 + 两部门循环 + 漏出/注入 + 连续互动追问 + 阶段性课程 Review
- 课程级组织方式：从宏观问题进入流量系统，再通过边界、时间和机制逐层压实
- 课节级组织方式：具体交易 → 初步判断 → 追问流向或边界 → 精确区分 → 新情境迁移
- 核心能力：追踪资金流相对于系统边界的变化，区分事后结果与事前计划，并从静态标签推进到动态机制
- 来源：用户提供的代表性课堂教学与 Review 材料
- 当前定位：经济学综合课的教学组织、互动推进和课程 Review 范例；不直接成为所有学科的固定模板

> 范围说明：本范例包含一段较完整的宏观经济学讲解，但采样重点不是覆盖了多少经济学知识，而是教师如何让学习者先判断、再暴露边界、继续追踪过程，并把课堂表现沉淀为有证据的课程 Review。

## 2. 这份范例为什么重要

宏观经济学面对的是一个很容易失控的对象：亿级的人、无数交易、价格和制度安排。课程没有试图逐笔解释现实，而是先提出一个更高层的问题：

> 能不能找到少数几个聚合变量，使整个经济体的运作变得可理解、可追踪？

“循环”因此不是一个要背下来的图，而是一种压缩复杂现实的观察方式。课程先把经济体看成流量系统，再不断逼问这个模型的边界：哪些流动离开了当前系统，哪些重新进入；同一笔钱相对于哪个系统、哪个时点和哪个部门被描述；一个事后总成立的等式究竟靠什么动态过程维持。

这份范例最值得保留的地方，是它没有把学习者的正确回答当成终点。用户三次判断都命中了大方向，但教师分别继续追问：

- 钱“漏”到哪里去了？
- 借入美元本身是否已经进入中国的人民币循环？
- 购买美国国债对中国国内循环的净效果是什么？
- 事后 `S = I` 靠什么机制成立？

于是，互动从“认出概念”转向“追踪对象、边界、时间和机制”。

## 3. 双层主线

### 3.1 课程导入主线

```text
真实经济体过于复杂
→ 需要用少数聚合变量压缩现实
→ 把经济体看成实物流和货币流组成的循环系统
→ 两部门循环揭示支出与收入的对称关系
→ 储蓄、税收和进口形成漏出，投资、政府支出和出口形成注入
→ 漏出与注入的判断必须相对于系统边界
→ 事后恒等式总能成立，但事前计划可以背离
→ 追踪库存、收入和产出调整，看到等式背后的动态过程
→ 用边界、时间和机制重新分析复杂交易
```

课程导入给出的不是一张静态知识地图，而是一条之后反复使用的观察路径：先把复杂对象转成流量系统，再检查这个系统如何被边界和时间切开。

### 3.2 课堂互动主线

```text
教师给出具体交易或判断题
→ 用户先做初步分类
→ 教师确认命中的部分
→ 追问资金流向、系统边界或后续流量
→ 用户暴露“对动作贴标签、没有追踪过程”的缺口
→ 教师引入更精确的区分
→ 用户在跨国、跨期或多部门情境中再次判断
→ 教师把当前表现收束为一个可迁移的思维动作
```

这条互动主线贯穿了三类问题：漏出与注入的相对性、系统边界的可移动性，以及事后结果与事前计划的区别。

## 4. 值得保留的教学机制

1. **先从复杂现实退一步**：不直接堆叠宏观指标，而是先说明为什么需要“循环”这种聚合视角。
2. **从两部门模型进入**：家庭和企业的实物流、货币流同时展开，让“支出同时是另一方收入”先成为可观察结构。
3. **在学生形成直觉后立即制造边界问题**：烧掉钱、埋钱、政府印钱等例子，迫使学习者意识到“普遍规律”有条件。
4. **让同一个标签在不同边界下改变性质**：买宝马、买奇瑞、中国对外贷款、全球经营系统等例子都服务于边界切换。
5. **对正确回答继续追问**：不把“答对”当作掌握证明，而是看用户能否说明流向、时间和机制。
6. **把融资行为拆成多个环节**：借美元、换成人民币、在中国建厂和未来还款分别处理，避免把一笔复杂交易压成一个标签。
7. **把静态等式推回真实过程**：用非意愿库存解释计划储蓄与计划投资背离如何转化为产出调整。
8. **用元认知停顿收束阶段**：不仅问用户哪里没听懂，也问哪种追问最有效，把互动方法本身纳入学习证据。
9. **在收束时留下可复用的问题**：最终不是记住“这是漏出还是注入”，而是记住“钱从哪个系统流出、进入哪个系统、是否会触发后续流量”。

## 5. 技术表述校准与使用边界

### 5.1 “每一笔支出同时是另一方收入”需要声明条件

这句话适合作为宏观会计的入口，但不能在所有语境下不加条件地使用。它依赖于：

- 选择了一个明确的系统边界。
- 交易和相关主体被纳入同一套核算。
- 分析的是被记录的经济交易，而不是财富被销毁、现金被闲置等未进入当期交易流的情形。

烧掉钱不是另一方的收入；把现金埋在地下也不会自动成为当期支出。这里的教学重点不是列举例外，而是让学习者发现“循环”本身就是一个有边界的模型。

### 5.2 漏出与注入不是动作的固定属性

在常用的宏观循环框架中：

| 漏出 | 注入 |
| --- | --- |
| 储蓄 `S` | 投资 `I` |
| 税收 `T` | 政府支出 `G` |
| 进口 `M` | 出口 `X` |

对应的国民收入恒等关系可以写成：

```text
S + T + M = I + G + X
```

但“漏出”不等于钱从现实中消失，也不等于一笔交易天然带有漏出属性。中国消费者购买德国汽车，对中国国内循环是进口带来的漏出；对德国循环则可能是出口收入，对全球经济则是跨主体的支付与收入转移。

因此，更精确的判断方式是：

> 这笔资金相对于哪个系统边界，从哪里流出，又流入了哪里？

### 5.3 事后恒等式与事前计划不能混为一谈

在封闭经济的简化情形下，事后核算中的实际储蓄和实际投资总是相等；但家庭计划储蓄和企业计划投资可以在事前不相等。

| 维度 | 事后 `ex post` | 事前 `ex ante` |
| --- | --- | --- |
| 是什么 | 会计核算结果 | 各方的计划与意图 |
| 是否必然相等 | 是 | 不一定 |
| 关键问题 | 结果如何记账 | 计划背离如何引发调整 |
| 典型机制 | 非意愿库存被计入实际投资 | 产出、收入、利率或价格发生变化 |

教学上需要避免一句“`S = I` 所以储蓄和投资没有问题”带过。等式成立并不代表计划协调已经完成；它可能是在库存积压和收入下降等真实失衡中成立的。

### 5.4 外币贷款不能直接等同于国内注入

中国企业从美国银行借美元用于在中国建厂，至少要拆成四个环节：

1. 借入美元：融资和负债形成，但美元仍在外币金融体系中，不能直接等同于人民币实体循环中的支出。
2. 美元兑换人民币：涉及外汇市场、人民币需求、汇率压力和可能的央行干预。
3. 人民币用于建厂：建筑工人工资、材料采购和设备购买形成投资支出，进入国内家庭和企业收入。
4. 未来还本付息：可能形成以人民币换回美元的跨境流出，是否可持续取决于项目收益、汇率和融资条件。

因此，建厂支出是最直接的国内投资注入；借款本身是融资安排；未来还款则是跨期分析中必须纳入的反向流量。

### 5.5 购买美国国债的净效果不应只用“资本流出”概括

如果中国用已经持有的美元外汇储备购买美国国债，这笔交易首先发生在美元资产配置和美国国债交易系统中。它不等于当期从在岸人民币系统中抽走同额人民币，也不等于当期增加中国国内实体支出。

在一个只问国内 GDP、就业和总需求的循环分析里，购买国债的当期净效果可以近似看作中性；但这不是说它没有代价：

- 选择国债意味着放弃购买外国技术设备、进行海外直接投资或持有其他资产的机会。
- 中国持有美元计价资产，要承担汇率、利率、信用和再投资风险。
- 资产负债表结构的变化，不会被单纯的循环流量框架完整捕捉。

这说明一个重要的适用边界：循环流量适合追踪支出、收入和资金流，但不自动解释资产负债表、风险结构和机会成本。

### 5.6 同一笔资金的判断随边界移动

系统边界至少可以沿三个维度移动：

| 维度 | 可能的选择 |
| --- | --- |
| 地理 | 一个城市、一个国家、全球 |
| 时间 | 本期、多期、跨代 |
| 部门 | 实体经济、金融系统、公共部门 |

“对中国是漏出、对中非双边系统是内部转移、对全球经济是资产重新配置、跨期看又包含未来还款”并不是四个互相矛盾的答案，而是在回答不同边界下的问题。

## 6. 校准后的课程导入范例

### 6.1 宏观经济学为什么需要循环视角

一个真实经济体里有无数人、企业、交易和价格。如果试图逐项理解，学习者很快会被细节淹没。宏观经济学先做一个压缩：寻找少数聚合变量，观察收入、支出、生产和资金如何相互连接。

循环视角的入口可以先用一句话表达：

> 每一笔被记录的支出，同时也是另一方的收入。

这句话的价值不在于它听起来简单，而在于它把分散的交易连接成一个可追踪的系统。课程随后会不断问：这个系统的边界在哪里？哪些流量暂时离开？什么力量会把它重新接通？

### 6.2 两部门循环

先只看家庭和企业：

```text
家庭 ──劳动、土地、资本──→ 企业
      ←──工资、地租、利润──

家庭 ←────商品与服务──── 企业
      ─────消费支出────→
```

图中同时有两层流动：

- 实物面：劳动要素从家庭进入企业，商品和服务从企业进入家庭。
- 货币面：工资、地租和利润成为家庭收入，消费支出成为企业收入。

于是，GDP从收入角度计算和从支出角度计算相等，并不是偶然巧合，而是同一组交易从两个方向被记录。

### 6.3 从封闭循环进入漏出和注入

现实经济不是封闭的。家庭可以储蓄，政府可以征税，消费者可以购买进口商品；企业可以投资，政府可以支出，国内企业可以出口。

这三组“破口”与“接入”把两部门循环扩展为更真实的系统：

```text
储蓄 S、税收 T、进口 M  → 暂时离开当前循环
投资 I、政府支出 G、出口 X → 从循环外或其他部门进入
```

这里的关键不是背下六个字母，而是理解它们相对于边界的含义。

## 7. 用户回答后的连续教学范例

### 7.1 第一轮：先判断“漏出、注入，还是既不是”

教师给出三个情形：

1. 一个中国消费者购买德国宝马汽车。
2. 中国政府发行国债，用于建设高铁。
3. 一个企业主把今年利润存入银行账户，但没有投资。

用户回答：

```text
买宝马——漏出
政府发债建高铁——注入
利润存银行但没有投资——漏出
```

教师没有直接纠正，而是逐项确认后继续追问。

买宝马确实是对中国国内循环的进口漏出，但教师马上补上一个空间边界：钱并没有从全球经济中消失，而是成为德国出口方的收入。

政府发债建高铁确实包含政府支出这一注入，但如果国债由中国居民购买，居民购买国债又可以被理解为储蓄。一个漏出被转化成了一个注入，不能简单理解成凭空增加了一笔资源。

利润存入银行但没有投资则需要继续问时刻和层次：企业主的计划储蓄可能暂时没有对应的计划投资；如果银行把资金贷给另一家企业投资，资金可能重新接通；如果资金沉淀在银行体系中，计划储蓄和计划投资的背离就会继续存在。

这一轮的教学动作是：**先承认分类方向，再把分类背后的边界和后续流量补出来。**

### 7.2 第二轮：把一笔外币贷款拆成过程

教师提出：

> 一个中国企业从美国银行借了一笔美元贷款，用于在中国建厂。对中国经济循环而言，涉及哪些漏出和注入？各发生在哪个环节？

用户回答把“借美债”和“在中国建厂”都判断为注入。教师指出，这个回答抓到了方向，但还没有拆解结构：

```text
借入美元
→ 美元仍在外币金融体系
→ 兑换成人民币，进入外汇市场和货币体系
→ 人民币用于工资、材料和设备支出
→ 国内家庭与企业获得收入
→ 未来还本付息，可能形成跨境反向流量
```

这里的关键纠偏不是把“注入”改成“不是注入”这么简单，而是把融资行为、货币兑换、实体支出和未来偿还分开。教师随后把用户的思维缺口明确说出来：

> 你在对动作贴标签，而不是在追踪流量。

然后给出一个可以重复使用的问题框架：

1. 这笔钱从哪个系统流出？
2. 流入了哪个系统？
3. 这是一次性的流量，还是会触发后续流量？
4. 将来有没有对应的反向流量？

### 7.3 第三轮：把框架迁移到美国国债

教师要求用户重新分析“中国政府购买 1000 亿美元美国国债”，不要只回答“资本流出”。

用户回答：

```text
流出的是中国的外汇储备系统，而非在岸人民币系统。
流入的是美国财政部的国债发行与交易系统。
后续会有定期利息回流、到期本金回流，以及汇率管理驱动的持续交易。
反向流量包括确定的到期还本、正在进行的主动减持和低概率的极端抛售。
```

教师先明确确认两点：

- 用户识别出了外汇储备系统与在岸人民币系统的边界差异。
- 用户完整列出了后续流量和反向流量。

但教师指出仍有一个未完成的问题：对中国 GDP、就业和国内总需求的净效果是什么？

进一步分析发现，外汇储备主要来自出口顺差和外资流入。中国出口收美元、央行买入美元并释放人民币的过程，才是国内人民币循环中更直接的注入；用已经持有的美元购买美国国债，更多是美元资产之间的重新配置。

因此，这个交易在单纯的国内循环流量视角下可以近似中性，但它仍然具有机会成本和资产负债表效应。教师由此把循环框架的适用边界也讲出来：一个分析工具很强，并不意味着它能捕捉所有问题。

### 7.4 第四轮：从元认知停顿进入下一层

课程在进入更复杂内容前，安排了一个阶段性停顿：

```text
回看学习路径：
两部门循环
→ 漏出与注入
→ 事后恒等式与事前计划
→ 系统边界
→ 资产负债表效应
```

教师连续问两个问题：

1. 哪个地方理解得最不扎实？
2. 哪种追问最有效，是划定边界、追踪流量，还是其他方式？

用户指出“事后恒等式 vs. 事前计划”和“系统边界”是薄弱点，同时认为划定边界和追踪流量都有效。

这个停顿很重要，因为它不只是收集满意度，而是读取用户对自己理解过程的判断，并让教学方法本身成为下一轮教学的输入。

## 8. 事后恒等式与事前计划：从结果追到机制

### 8.1 精确区分

```text
事后：会计核算的结果，S = I 永远成立
事前：家庭与企业的计划，计划储蓄可以不等于计划投资
```

很多学习者看到“`S = I` 永远成立”就以为储蓄和投资之间没有问题。教师没有停在定义，而是问：这个等式究竟靠什么机制维持？

### 8.2 非意愿库存作为减震器

设想封闭经济中：

- 家庭计划储蓄 1000 元。
- 企业计划投资 800 元。
- 企业按预期需求生产，但家庭少购买了 200 元商品。

这 200 元商品没有卖出去，堆在仓库里。国民账户把它计入非意愿库存投资：

```text
实际投资 = 计划投资 800 + 非意愿库存 200 = 1000
实际储蓄 = 1000
→ S = I 成立
```

但等式成立的同时，经济已经发生了真实失衡。企业看到库存增加，削减产量；产量下降导致收入下降；家庭收入下降后，储蓄也会下降，直到计划储蓄和计划投资重新接近。

库存像一个减震器：它让会计等式在每个时点都能成立，同时把计划背离转化为产出和收入波动。

### 8.3 让用户追踪一个最小变化

教师随后提出：

> 假设中国家庭突然决定多储蓄 20%，请一步一步追踪经济会发生什么；在哪一步，事后 `S = I` 重新成立；均衡恢复后，经济里什么东西已经永久改变？

这道题不是要求用户重复“储蓄增加所以投资增加”，而是要求用户说出完整因果链，并指出库存在哪一步出现。互动停在了真正的理解边界：用户是否能把一个静态等式还原为动态调整过程。

## 9. 系统边界：同一笔钱的不同答案

### 9.1 三个可移动维度

系统边界不是自然事实，而是由分析问题选择的建模边界。至少有三种移动方式：

```text
地理：城市 / 国家 / 全球
时间：本期 / 多期 / 跨代
部门：实体经济 / 金融系统 / 公共部门
```

最常见的错误，是默认地理边界等于国界、时间边界等于当期、部门边界等于实体经济。一笔交易只要跨越其中一个维度，结论就可能发生变化。

### 9.2 同一交易的四种判断

以中国对非洲基础设施贷款为例：

| 分析边界 | 这笔交易的性质 |
| --- | --- |
| 中国国内循环 | 资本流出、对国内是漏出 |
| 中非双边系统 | 系统内部的资金转移 |
| 全球经济 | 资产重新配置，整体上近似中性 |
| 跨期边界 | 当前向非洲提供资金，未来可能通过还款形成反向流量 |

四个答案都可能正确，因为它们回答的是不同问题。没有声明边界的“漏出/注入”判断是不完整的。

### 9.3 比亚迪在匈牙利建厂

教师用一个更复杂的迁移任务测试用户：比亚迪在匈牙利建厂，生产汽车销售给欧洲消费者；资金来自中国总部利润留存；工人是匈牙利本地人；核心零件从中国进口。

任务被拆成三问：

1. 对中国国内循环，各笔资金流是漏出还是注入？
2. 如果边界扩大到比亚迪全球经营系统，判断如何变化？
3. 哪个环节可能产生反向流量回到中国，什么条件会让它变大或变小？

这不是要求用户给出一个标签，而是要求先声明边界，再追踪资金从哪里来、流到哪里、未来怎样回来。

## 10. 适合宏观经济循环教学的互动节点

1. **普遍规律的边界**：支出何时同时是收入，何时不进入当前循环？
2. **简单分类题**：交易属于漏出、注入还是既不是？分类后立刻追问“漏到哪里”。
3. **融资与支出的区分**：借款本身、货币兑换、实体投资和还款分别发生了什么？
4. **跨系统流动**：同一笔钱对中国、美国、全球和不同子系统分别意味着什么？
5. **跨期反向流量**：当前注入未来会不会形成还款、收益或其他回流？
6. **事后与事前**：等式为什么永远成立，计划为什么仍然可能背离？
7. **库存机制**：非意愿库存如何把计划差异转成产出波动？
8. **工具边界**：循环流量框架解释了什么，又遗漏了资产负债表和机会成本的哪些部分？
9. **元认知 Review**：哪类追问改变了你的判断，为什么？

这些节点的共同点不是题型相同，而是每次都把学习者从“知道一个术语”推进到“说明判断成立的条件”。

## 11. 对课程生成架构的启示

### 11.1 主题主线应保存理解变化，不保存知识点清单

本课真正的主线不是“依次讲两部门、漏出注入、恒等式、边界、资产负债表”，而是：

```text
从把经济理解为钱在流
→ 到能声明系统边界
→ 能追踪当前与未来流量
→ 能区分事后结果和事前计划
→ 能判断一个分析框架的适用范围
```

这些内容之所以能连在一起，是因为它们共同压实“静态标签背后的条件和过程”。

### 11.2 互动不是正文旁路，而是正文控制信号

教师根据用户的回答改变下一段教学：

- 用户分类正确但没有说明边界，就追问“漏到哪里”。
- 用户把借款和建厂都称为注入，就拆分融资、兑换、支出和还款。
- 用户准确分析外汇储备流量，但没有判断净效果，就把问题推进到 GDP、就业和总需求。
- 用户承认事后恒等式和系统边界薄弱，就回到库存机制和边界选择。

这符合动态互动课程的基本形态：

```text
读取用户回答
→ 确认成立部分
→ 找到一个关键缺口
→ 选择下一教学动作
→ 生成新的可回答对象
```

### 11.3 学科方法应进入主线，但不能变成卡片模板

经济学在本案例中的学科方法是追踪流量、声明边界、区分时期和识别机制。它应帮助生成器选择例子、反例和追问，但不应变成每一节课都必须逐项填充的固定栏目。

换到计算机课程，类似位置可能由“结构约束 → 操作代价”承担；换到哲学课程，可能由“论证前提 → 反例压力 → 理论修正”承担。可迁移的是学科方法参与教学主线的方式，不是宏观经济学的术语。

### 11.4 内容结构和视觉容器应服务于理解

本课适合使用循环图、流向图、时间线、对照表和分步拆解，但每种表示都对应一个理解任务：

- 循环图承载部门之间的双向流动。
- 对照表区分事后和事前。
- 时间线承载当前注入与未来反向流量。
- 分步拆解区分融资、兑换、实体支出和还款。

不能因为有统一卡片槽位，就让所有内容平均变成图、表、公式、案例和互动。展示容器应在教学判断完成后被选择。

### 11.5 Review 应由互动证据生成，而不是由大纲摘要生成

本课的 Review 没有重新罗列所有经济学概念，而是读取了用户回答中的两类证据：

- 能快速接受新框架，并在外汇储备问题中精确区分系统边界。
- 仍容易把动作归类为注入/漏出，而不继续追踪动态过程。

因此，复盘写的是“你如何理解、哪里会停住、下一次怎么做”，而不是“本课讲了什么”。

### 11.6 从本范例提炼的元方法

这份范例的学习重点不是复制“两部门循环 → 漏出注入 → 系统边界 → 事后恒等式”的章节顺序，而是观察课程如何用一个中心分析动作组织内容：先给出静态分类，再让分类在跨系统、跨期和动态机制中变得不充分，迫使学习者升级判断。

可迁移的设计流是：从一个可用但不完整的直觉进入，保留学习者已经成立的部分，再引入一个会改变判断的边界、条件或后续过程。经济学中的“追踪流量”只是该学科的实现方式；其他学科需要找到自己的过程追踪动作，不能把漏出、注入或系统边界变成通用模板。

## 12. 课程回顾范例：宏观经济循环

### 12.1 复盘定位

- 复盘对象：两部门循环、漏出与注入、系统边界、事后恒等式与事前计划
- 复盘形式：本课核心 + 具体表现证据 + 持续思维模式 + 下一步练习
- 复盘重点：区分“能使用框架”和“能追踪框架背后的过程”
- 语言风格：具体、克制、基于回答，不把内部评估字段直接展示给用户

这份 Review 不是把整节课重新讲一遍，而是把用户已经走过的理解变化压缩成可回看的学习资产。

### 12.2 面向用户的复盘输出

#### 本课核心：三条线索

**第一条：漏出与注入的本质**

不是动作的属性标签，而是资金流向相对于系统边界的描述。

- 三个基本漏出：储蓄、税收、进口。
- 三个基本注入：投资、政府支出、出口。

**第二条：系统边界是建模选择，不是自然给定的**

边界有三个维度：地理、时间、部门。同一笔钱，边界不同，答案不同。没有声明边界的判断是不完整的判断。

**第三条：事后恒等式 vs. 事前计划**

| 事后 | 事前 |
| --- | --- |
| `S = I` 永远成立 | 计划储蓄和计划投资可以背离 |
| 会计核算结果 | 各方的计划与意图 |
| 非意愿库存充当减震器 | 背离触发产出、收入等调整 |

等式总成立，但靠什么维持才是真正的问题。

**本课最重要的一句话**

> 追踪流量，不要贴标签。

在静态结果后面，看到动态过程；在概念标签后面，看到系统边界、时间范围和机制条件。

#### 你的表现

**明显的强项**

你接受新框架的速度很快，也能把它迁移到新情境。外汇储备那道题的回答尤其精确：你主动区分了“在岸人民币系统”和“外汇储备系统”，这不是简单贴标签，而是在真实追踪流量。

**一个持续出现的模式**

你倾向于先识别类型，而不是继续追踪过程。在简单情形下，这已经足够开始判断；但在非意愿库存、外币贷款和跨期反向流量等复杂情境中，这个习惯会让你停在正确的标签上，却错过真正的动态。

**接下来的练习**

下次分析一笔经济交易时，强制自己先回答四个问题：

1. 这笔钱从哪个系统流出？
2. 流入了哪个系统？
3. 这是一次性的，还是会触发后续流量？
4. 将来有没有对应的反向流量？

不要先写“漏出”或“注入”，先把流量路径写出来，再给它命名。

### 12.3 复盘内容与后台证据的分工

用户端展示的是已经转化后的自然反馈；后台可以保留更细的课堂证据：

```text
用户的分类回答
→ 教师确认命中的部分
→ 追问边界、时点或后续流量
→ 用户暴露概念跳步
→ 用户在新情境中给出更精确的边界判断
→ Review 选择一个持续模式并生成下一步练习
```

后台可以记录：

- 用户原始回答。
- 已成立的推理。
- 追问类型：边界、流量、时间、机制或工具边界。
- 缺口类型：只贴标签、未声明边界、未追踪过程、未判断净效果。
- 后续回答是否出现了可观察的修正。

但用户端不应直接显示“认知节点未完成”“命中评估维度”等内部语言，而应转化为：“你已经能区分……；下一步请继续说明……”。

### 12.4 该复盘样例的生成原则

1. 先重建用户真正走过的知识关系，不按课程大纲重新罗列全部概念。
2. 强项必须引用具体回答证据，不能只写“理解得很好”。
3. 薄弱点只选择一个最值得继续推进的思维模式，避免把 Review 写成错误清单。
4. 区分“概念错误”和“正确框架使用得不够深入”。本案例中的主要问题属于后者。
5. 把缺口转译成下一次可执行的回答动作，而不是只给评价。
6. 如果没有足够的检测或回答证据，应降低“掌握”“扎实”等结论的强度。
7. Review 既要总结本课，也要保留下一轮学习自然产生的问题。

### 12.5 可迁移的经济学复盘资产

这节课最终沉淀的不是六个漏出/注入名词，而是三种可复用的分析动作：

- 在给概念命名之前，先追踪资金的起点、终点和后续流量。
- 在做判断之前，明确地理、时间和部门边界。
- 在看到恒等式或静态结果时，继续追问它由什么机制维持。

后续课程可以要求学习者用这三种动作分析财政赤字、国际收支、货币政策或债务可持续性，而不是再次背诵循环流量图。

## 13. 该范例的表达方式不能全局复制

- 流向图、漏出/注入表和 GDP 恒等式适合经济学，但不能作为所有课程的统一视觉骨架。
- “先声明边界”适合建模类问题；在某些事实记忆型课程中，直接给出准确事实可能更有效。
- 连续追问需要建立在用户已有回答之上，不能把每个课节都强行变成苏格拉底式问答。
- 元认知停顿适合在一段真实理解变化之后使用，不应机械安排在每节课固定位置。
- 本课的优势来自“内容结构、互动动作和学科方法相互咬合”，不是来自问题数量、表格数量或追问次数。
